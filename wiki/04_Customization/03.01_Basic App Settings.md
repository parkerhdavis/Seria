# Basic App Settings

Seria's settings dialog provides quick access to all user preferences. Open it with `Ctrl+,` or via the gear icon in the toolbar.

---

## Accessing Settings

**Three ways to open:**
1. **Keyboard:** Press `Ctrl+,`
2. **Toolbar:** Click the gear icon
3. **Menu:** File → Settings (if menu bar is visible)

The settings dialog is organized into sections for easy navigation.

---

## Appearance

### Theme

**Options:**
- **Light** - Light background, dark text
- **Dark** - Dark background, light text
- **System** (coming soon) - Follow OS theme

**Shortcut:** `Ctrl+T` to toggle between light and dark

**Applies:** Immediately, globally (all files)

---

### Font Size

**Options:**
- Default: 12pt
- Range: 8pt to 24pt

**Shortcuts:**
- `Ctrl+=` or `Ctrl++` - Increase font size
- `Ctrl+-` - Decrease font size
- `Ctrl+0` - Reset to default

**Applies:** Cell View and Print View font sizes

**Note:** Font size in Print View depends on the recipe - some recipes have fixed font sizes for formatting reasons.

---

### Grid Zoom

**Options:**
- Default: 100%
- Range: 50% to 200%

**Shortcuts:**
- `Ctrl+=` - Zoom in
- `Ctrl+-` - Zoom out
- `Ctrl+0` - Reset to 100%

**Applies:** Cell View grid (affects row height, column spacing)

**Saved:** Per-file (different CSVs can have different zoom levels)

---

### Density

**Options:**
- **Compact** - Tighter spacing, more rows visible
- **Normal** - Balanced spacing (default)
- **Comfortable** - Extra padding, easier to read

**Applies:** Row height and cell padding in Cell View

---

## File Saving

### Auto-Save

**Enable/disable:** Toggle checkbox

**Interval:** 5 seconds to 5 minutes (default: 30 seconds)

**How it works:**
- Timer starts after you finish editing a cell
- If you edit another cell, timer resets
- When timer reaches zero, file is automatically saved
- Visual feedback briefly shows "Saved" in status bar

**Recommended for:**
- Most users - protects work without thinking about it
- Users who don't use version control

**Disable for:**
- Git workflows where you want manual control over commits
- Working on critical files where you want explicit save points

---

### Backup Files

**Enable/disable:** Toggle checkbox (default: enabled)

**How it works:**
- Before saving, creates a backup with `.backup` extension
- Keeps the most recent backup only
- Useful for recovering from accidental changes

**Location:** Same directory as the original file

**Example:**
```
dialogue.csv          # Current file
dialogue.csv.backup   # Previous version
```

---

### Confirm Before Closing Unsaved Files

**Enable/disable:** Toggle checkbox (default: enabled)

**Behavior:**
- Enabled: Prompts "Save changes?" when closing unsaved file
- Disabled: Closes without asking (relies on auto-save)

---

## Editor

### Edit Mode

**Options:**
- **Double-click** - Double-click cell to edit (default)
- **Single-click** - Single-click to edit (faster but less safe)
- **F2 only** - Only F2 key starts editing (most precise)

**Recommendation:** Start with double-click, try F2-only if you prefer keyboard-first workflow.

---

### Tab Behavior

**Options:**
- **Move to next column** (default)
- **Insert tab character** - For cells that need literal tabs

**Note:** Most users want "Move to next column" for quick data entry.

---

### Enter Behavior

**Options:**
- **Save and move to next row** (default)
- **Save and stay in same cell**
- **Save and move to next column**

**Recommendation:** Default is optimized for row-by-row data entry.

---

### Show Grid Lines

**Enable/disable:** Toggle checkbox (default: enabled)

**Effect:** Show/hide grid lines between cells in Cell View

---

### Line Numbers in Print View

**Enable/disable:** Toggle checkbox (default: disabled)

**Effect:** Shows CSV row numbers in Print View for reference

---

## Print Templates

### Manage Custom Templates

**Actions:**
- **Import** - Load a custom Print recipe JSON file
- **Export** - Save a custom recipe to share
- **Delete** - Remove a custom recipe
- **Edit** - Open recipe in editor (coming soon)

**Location:** Custom recipes are stored in:
- Linux: `~/.config/seria/prints/`
- Windows: `%APPDATA%\seria\prints\`
- macOS: `~/Library/Application Support/seria/prints/`

See [Custom Recipes](wiki/04_Customization/03.04_Custom%20Recipes.md) for how to create them.

---

### Default Print Template

**Options:** Select which Print recipe to use by default when opening files

**Applies:** To files that don't have a saved Print preference

**Per-file override:** Each file remembers its last-used Print template

---

## Advanced

### Developer Mode

**Enable/disable:** Toggle checkbox (default: disabled)

**Enables:**
- Developer console (press `F12`)
- Debug logging
- Experimental features
- Reload with `Ctrl+R`

**Warning:** Developer mode may expose features that are incomplete or unstable.

---

### Performance

**Options:**
- **Virtualization threshold** - How many rows before using virtualization (default: 100)
- **Debounce interval** - Delay before applying filters/searches (default: 300ms)

**For most users:** Leave at defaults

**For power users with large CSVs:** Adjust if performance is sluggish

---

### Telemetry

**Status:** Seria does not collect any telemetry or usage data.

**Privacy:** Your data never leaves your computer. No analytics, no tracking, no phone-home.

## Reset to Defaults

**Button:** "Reset All Settings"

**Warning:** This resets ALL settings to defaults. Your custom Print templates are preserved.

**To completely reset Seria:**
1. Close Seria
2. Delete config directory (see [Where the Files Are](wiki/01_Introduction/00.04_Where%20the%20Files%20Are.md))
3. Restart Seria

## Platform Differences

### Linux

- Settings stored in `~/.config/seria/`
- Theme matches GTK theme (coming soon)

### Windows

- Settings stored in `%APPDATA%\seria\`
- Integrates with Windows dark mode setting (coming soon)

### macOS

- Settings stored in `~/Library/Application Support/seria/`
- Respects system accent color (coming soon)

## Tips

**Experiment without fear:**
- All settings can be changed back
- "Reset to Defaults" button restores everything
- Per-file settings are separate from global settings

**Keyboard shortcuts are your friend:**
- `Ctrl+,` to open settings is faster than clicking
- `Ctrl+T` for quick theme toggle
- `Ctrl+=/-` for quick zoom adjustments

**Auto-save trade-offs:**
- Enabled: Never lose work, but less control over when saves happen
- Disabled: Manual control, but you have to remember to save

**Developer mode:**
- Useful if you're creating custom recipes
- Lets you reload the app quickly while testing
- Can help troubleshoot issues with support
