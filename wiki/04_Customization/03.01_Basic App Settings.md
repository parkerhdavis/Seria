# Basic App Settings

Seria's settings dialog provides quick access to all user preferences. Open it with `Ctrl+,` or via the gear icon in the toolbar.

---

## Accessing Settings

**Two ways to open:**
1. **Keyboard:** Press `Ctrl+,`
2. **Toolbar:** Click the gear icon

The settings dialog is organized into sections for easy navigation.

---

## Appearance

### Theme

**Options:**
- **Light** - Light background, dark text
- **Dark** - Dark background, light text (default)
- **Auto** - Follow OS theme

**Applies:** Immediately, globally (all files)

---

### App Font

**Options:**
- **System Default** - Uses your OS system font
- **Courier Prime** - Monospace screenwriting font

**Applies:** Application UI (not Print views, which use recipe-defined fonts)

---

### Zoom

**Shortcuts:**
- `Ctrl+=` or `Ctrl++` - Zoom in (10% increments, max 200%)
- `Ctrl+-` - Zoom out (10% increments, min 50%)
- `Ctrl+0` - Reset to 100%

**Applies:** Entire application view

---

### Toolbar Controls

Additional appearance settings are available directly in the editor toolbar:
- **Wrap Text** - Toggle text wrapping in cells
- **Column Separators** - Toggle column separator lines
- **Row Coloring** - Off, alternating, or by-field coloring modes

---

## Editor

### Show Non-Cell Files

**Enable/disable:** Toggle checkbox (default: disabled)

**Effect:** When enabled, non-CSV/TSV files appear in the file tree sidebar (greyed out and non-clickable). Useful for seeing the full directory structure.

---

### Hover Highlighting

**Options:**
- **None** - No hover highlight
- **Row** - Highlight the entire row on hover
- **Column** - Highlight the entire column on hover
- **Row and Column** - Highlight both row and column on hover (default)

**Applies:** Cell View grid

---

### Bidirectional Editing

Controls how the Cell View and Print View stay in sync:

**Print follows Cell edit** (default: enabled)
- Automatically scrolls Print view to show the element being edited in Cell view

**Cell follows Print edit** (default: enabled)
- Automatically scrolls Cell view to show the row being edited in Print view

---

## File Saving

### Auto-Save

**Enable/disable:** Toggle checkbox (default: enabled)

**Interval:** 5 seconds to 5 minutes (default: 30 seconds)

**How it works:**
- After you confirm a cell edit (press Enter, Tab, or click away), the autosave timer starts
- If you make another edit before the timer expires, the timer resets
- When the timer reaches zero, your file is automatically saved

**Quick presets:** 10s, 30s, 1m, 2m, 5m buttons for easy configuration

**Recommended for:**
- Most users - protects work without thinking about it
- Users who don't use version control

**Disable for:**
- Git workflows where you want manual control over commits
- Working on critical files where you want explicit save points

---

### Autocomplete

**Enable/disable:** Toggle checkbox (default: enabled)

**Minimum characters:** 0-5 (default: 1)
- Set to 0 to show all column values immediately when editing

**Restrict to existing values:** Toggle checkbox (default: disabled)
- When enabled, only allows values that already exist in the column

**How it works:**
- When editing a cell, autocomplete shows suggestions based on existing values in that column
- Use Arrow Up/Down to navigate, Enter/Tab to select, or Escape to dismiss

---

## File Configuration Management

### Export Configs

Export your per-file configurations as a JSON file. Useful for:
- Backing up your settings
- Sharing configurations with team members
- Moving settings to a new machine

### Import Configs

Import per-file configurations from a previously exported JSON file.

### Cleanup Old Configs

Remove configurations for files that haven't been opened in 180 days.

---

## Recent Files

View and manage your recently opened files:
- Click a recent file to reopen it
- Clear the recent files list

## Tips

**Experiment without fear:**
- All settings can be changed back
- Per-file settings are separate from global settings

**Keyboard shortcuts are your friend:**
- `Ctrl+,` to open settings is faster than clicking
- `Ctrl+=/-` for quick zoom adjustments

**Auto-save trade-offs:**
- Enabled: Never lose work, but less control over when saves happen
- Disabled: Manual control, but you have to remember to save
