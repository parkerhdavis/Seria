# Keyboard Shortcuts Reference

Complete reference of keyboard shortcuts in Seria.

**Note:** Shortcuts listed use Windows/Linux notation. Seria currently supports Windows and Linux. macOS support is planned for a future release.

---

## File Operations

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Open file** | `Ctrl+O` | Opens file dialog |
| **Save file** | `Ctrl+S` | Saves current file (Save As for temp files) |

---

## Editing

### Basic Editing

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Edit selected cell** | `F2` or `Enter` | Starts editing mode |
| **Cancel edit** | `Escape` | Discards changes |
| **Save & next row** | `Enter` | Saves and moves down |
| **Save & previous row** | `Shift+Enter` | Saves and moves up |
| **Save & next column** | `Tab` | Saves and moves right |
| **Save & previous column** | `Shift+Tab` | Saves and moves left |

### Selection

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Move selection** | `Arrow keys` | Navigate cells |
| **Select range** | `Shift+Arrow keys` | Extend selection |
| **Select all** | `Ctrl+A` | Selects entire CSV |
| **Clear selection** | `Escape` | Deselects cells |
| **Toggle multi-cursor** | `Ctrl+Click` | Add/remove cursor |
| **Clear multi-cursors** | `Escape` | Remove all secondary cursors |

### Clipboard

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Copy** | `Ctrl+C` | Copy selected cells |
| **Paste** | `Ctrl+V` | Paste to selection |
| **Cut** | `Ctrl+X` | Cut selected cells |

### Undo/Redo

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Undo** | `Ctrl+Z` | Undo last action |
| **Redo** | `Ctrl+Shift+Z` or `Ctrl+Y` | Redo undone action |

## Find, Replace, and Navigate

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Find** | `Ctrl+F` | Opens find dialog |
| **Find and Replace** | `Ctrl+R` | Opens replace dialog |
| **Find next** | `F3` or `Enter` | In find dialog |
| **Find previous** | `Shift+F3` or `Shift+Enter` | In find dialog |
| **Close find** | `Escape` | Closes find dialog |
| **Go to row/column** | `Ctrl+G` | Opens go-to dialog |

## View and Navigation

### Panels

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Toggle left sidebar** | `Ctrl+.` | File tree |
| **Toggle Print preview (right)** | `Ctrl+\` | Right panel |
| **Toggle Print preview (bottom)** | `Ctrl+/` | Bottom panel |
| **Open settings** | `Ctrl+,` | Settings dialog |
| **Column manager** | `Ctrl+M` | Manage columns |

### Zoom

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Zoom in** | `Ctrl+=` or `Ctrl++` | 10% increments, max 200% |
| **Zoom out** | `Ctrl+-` | 10% increments, min 50% |
| **Reset zoom** | `Ctrl+0` | Back to 100% |

### Jump to

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Jump to cell** | `Ctrl+G` | Opens go-to dialog |
| **Jump to top** | `Ctrl+Home` | First cell |
| **Jump to bottom** | `Ctrl+End` | Last cell |
| **Jump to row start** | `Home` | First column |
| **Jump to row end** | `End` | Last column |

### Workspace Layouts

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Workspace manager** | `Ctrl+Shift+W` | Save/load layouts |
| **Quick switch layout 1-9** | `Ctrl+1` through `Ctrl+9` | Switch to saved layout |

### Autocomplete

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Navigate suggestions** | `Arrow Up/Down` | While autocomplete is open |
| **Select suggestion** | `Enter` or `Tab` | Apply selected value |
| **Close autocomplete** | `Escape` | Dismiss suggestions |

## Context Menu

Right-click any cell, row number, or column header to access context menu with:
- Insert row above/below
- Delete row(s)
- Insert column left/right
- Delete column
- Rename column
- Copy/Paste
- Clear cell(s)
- Filter by this value

## Tips for Efficient Workflow

### Data Entry Workflow

1. `F2` - Start editing
2. Type value
3. `Tab` - Save and move right
4. Repeat for entire row
5. `Enter` at end of row to move to next row

### Rapid Navigation

- `Ctrl+Home` - Jump to top
- `Arrow keys` - Navigate
- `Ctrl+End` - Jump to bottom
- `Home` - Jump to row start
- `End` - Jump to row end

### Quick Filtering

1. Click filter icon in column header
2. Type filter value
3. `Enter` to apply
4. `Escape` to close filter dropdown

### Multi-Cell Editing

1. Select range with `Shift+Arrow keys`
2. `Ctrl+C` to copy
3. Select destination
4. `Ctrl+V` to paste
5. `Ctrl+Z` if you need to undo

**Most Essential Shortcuts:**
- `Ctrl+O` - Open file
- `Ctrl+S` - Save file
- `F2` - Edit cell
- `Enter` - Save & next row
- `Tab` - Save & next column
- `Ctrl+C` - Copy
- `Ctrl+V` - Paste
- `Ctrl+Z` - Undo
- `Ctrl+F` - Find
- `Ctrl+\` - Toggle Print preview

**Master these first, then explore the others.**
