# Keyboard Shortcuts Reference

Complete reference of keyboard shortcuts in Seria.

**Note:** Shortcuts listed use Windows/Linux notation. For macOS:
- `Ctrl` → `Cmd` (Command key)
- `Alt` → `Option`

---

## File Operations

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Open file** | `Ctrl+O` | Opens file dialog |
| **Save file** | `Ctrl+S` | Saves current file |
| **Save As** | `Ctrl+Shift+S` | Save to new location |
| **Close file** | `Ctrl+W` | Prompts if unsaved |
| **Quit application** | `Ctrl+Q` | Closes Seria |

---

## Editing

### Basic Editing

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Edit selected cell** | `F2` or `Enter` | Starts editing mode |
| **Cancel edit** | `Escape` | Discards changes |
| **Save & next row** | `Enter` | Saves and moves down |
| **Save & previous row** | `Shift+Enter` | Saves and moves up |
| **Save & next column** | `Tab` | Saves and moves right |
| **Save & previous column** | `Shift+Tab` | Saves and moves left |

### Selection

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Move selection** | `↑` `↓` `←` `→` | Arrow keys |
| **Select range** | `Shift+↑↓←→` | Extend selection |
| **Select all** | `Ctrl+A` | Selects entire CSV |
| **Clear selection** | `Escape` | Deselects cells |

### Clipboard

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Copy** | `Ctrl+C` | Copy selected cells |
| **Paste** | `Ctrl+V` | Paste to selection |
| **Cut** | `Ctrl+X` | Cut selected cells |

### Undo/Redo

| Action | Shortcut | Notes |
|--------|----------|-------|
| **Undo** | `Ctrl+Z` | Undo last action |
| **Redo** | `Ctrl+Shift+Z` or `Ctrl+Y` | Redo undone action |

## Tips for Efficient Workflow

### Data Entry Workflow

1. `F2` - Start editing
2. Type value
3. `Tab` - Save and move right
4. Repeat for entire row
5. `Enter` at end of row to move to next row

### Rapid Navigation

- `Ctrl+Home` - Jump to top
- `↓↓↓` - Navigate down
- `Ctrl+End` - Jump to bottom
- `Home` - Jump to row start
- `End` - Jump to row end

### Quick Filtering

1. Click filter icon in column header
2. Type filter value
3. `Enter` to apply
4. `Escape` to close filter dropdown

### Multi-Cell Editing

1. Select range with `Shift+↑↓←→`
2. `Ctrl+C` to copy
3. Select destination
4. `Ctrl+V` to paste
5. `Ctrl+Z` if you need to undo

## Platform Differences

### Windows/Linux vs macOS

| Operation | Windows/Linux | macOS |
|-----------|---------------|-------|
| **Undo** | `Ctrl+Z` | `Cmd+Z` |
| **Copy** | `Ctrl+C` | `Cmd+C` |
| **Paste** | `Ctrl+V` | `Cmd+V` |
| **Save** | `Ctrl+S` | `Cmd+S` |
| **Find** | `Ctrl+F` | `Cmd+F` |

Most `Ctrl` shortcuts become `Cmd` shortcuts on macOS.

### Linux-Specific Notes

Some shortcuts may conflict with desktop environment shortcuts:
- `Ctrl+Q` may close the terminal (if launched from terminal)
- `Ctrl+.` may conflict with some window managers
- Check your desktop environment's shortcut settings if issues arise
