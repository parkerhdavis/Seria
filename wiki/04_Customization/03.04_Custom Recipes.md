# Custom Print Recipes

Custom Print Recipes allow you to create your own templates for displaying CSV data in custom formats.

## Creating Custom Recipes

Custom recipes are JSON files that define how CSV columns map to formatted output. For a detailed guide on creating custom recipes, including JSON template structure, styling options, and installation, see the [Custom Prints Guide](wiki/03_Print%20View/02.02_Print%20Recipes.md).

## Managing Custom Recipes

Custom recipes are stored in your Seria data directory:
- **Linux:** `~/.local/share/Seria/prints/`
- **Windows:** `%LOCALAPPDATA%\seria\prints\`
- **macOS:** `~/Library/Application Support/seria/prints/`

### Adding a Custom Recipe

1. Create a JSON file following the template structure (see [Custom Prints Guide](wiki/03_Print%20View/02.02_Print%20Recipes.md))
2. Place it in the `prints/` directory above
3. Restart Seria
4. Select your custom recipe from the Print template dropdown

### Sharing Recipes

Custom recipes are portable JSON files. Share them with collaborators by:
1. Copying the JSON file from your `prints/` directory
2. Having others place it in their own `prints/` directory

## Visual Recipe Editor

A visual recipe editor is planned for a future release that will let you create recipes without writing JSON.
