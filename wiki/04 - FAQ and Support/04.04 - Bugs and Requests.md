## Reporting Bugs

### How to report an issue

If you've found a bug not listed here:

1. **Check existing issues:** [GitLab Issues](https://gitlab.com/parkerhdavis/Seria/-/issues)
2. **Gather information:**
   - Operating system and version
   - Seria version (Help → About)
   - Steps to reproduce
   - Expected vs actual behavior
   - Error messages (if any)
3. **Create new issue:** [Report on GitLab](https://gitlab.com/parkerhdavis/Seria/-/issues/new)

**Include:**
- Clear description of problem
- Steps to reproduce
- Screenshots (if helpful)
- Sample CSV file (if relevant and non-confidential)
