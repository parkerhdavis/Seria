# Frequently Asked Questions

Common questions about Juniper.

---

## General

### What is Juniper?

Juniper is a specialized desktop CSV editor designed for writers and designers who use CSV data in creative workflows. It combines spreadsheet-like editing with professional document previews (called "Prints") that format your CSV data into polished page layouts.

### Is Juniper free?

Yes, Juniper is free and open-source software.

### What platforms does Juniper support?

Juniper runs on:
- **Linux** (Ubuntu, Fedora, Arch, and most modern distributions)
- **Windows** (Windows 10 version 1809 and later)
- **macOS** (macOS 10.15 Catalina and later)

### How is Juniper different from Excel or Google Sheets?

Juniper is **not** a replacement for spreadsheet applications. It's designed specifically for creative data workflows:

**Juniper has:**
- Print system for professional document formats
- Bidirectional editing (edit data in formatted preview)
- Fast, lightweight desktop app
- Focused feature set for narrative and design data

**Juniper doesn't have:**
- Formulas or calculations
- Charts and graphs
- Pivot tables
- Financial functions
- Cloud sync

See [About Juniper](00-About-Juniper.md) for more details.

### Why CSV and not Excel (.xlsx) format?

CSV is:
- **Simple** - Plain text format, human-readable
- **Universal** - Supported by every tool
- **Version control friendly** - Works great with Git
- **Lightweight** - No bloat from formatting/formulas

Juniper focuses on structured data, not spreadsheet calculations, so CSV is a perfect fit.

## Features

### Can I edit column headers?

Yes! Column headers are editable just like regular cells. Double-click a header to edit it.

### Can I add/delete rows and columns?

**Rows:**
- ✅ Add rows: `Ctrl+Enter` or right-click → Insert Row
- ⏳ Delete rows: Coming in a future update

**Columns:**
- ✅ Add columns: Right-click → Insert Column Left/Right
- ⏳ Delete columns: Coming in a future update

### Does Juniper support formulas or calculations?

No. Juniper is designed for creative data (dialogue, story beats, game items), not financial calculations.

If you need calculations, use Excel or Google Sheets to compute values, then export to CSV and open in Juniper.

### Can I work with multiple CSV files at once?

Not yet. Juniper currently supports one file at a time. Multiple file support is planned for a future release.

**Workaround:** Open multiple Juniper windows (launch the app multiple times).

### How large of a CSV can Juniper handle?

**Tested limits:**
- **< 1,000 rows:** Excellent performance
- **1,000 - 10,000 rows:** Good performance (automatic virtualization)
- **10,000 - 50,000 rows:** Acceptable performance (may see some lag)
- **50,000+ rows:** Consider splitting into multiple files

File size also depends on number of columns and content length.

### Does Juniper auto-save?

No. Juniper does not auto-save your changes.

**Best practice:** Save frequently with `Ctrl+S`.

**Why no auto-save?** To give you control over when changes are written to disk. This is important when working with version-controlled CSV files.

## Print System

### What are "Prints"?

Prints are customizable preview formats that display your CSV data as professional documents. For example, a Screenplay Print transforms dialogue CSV data into properly formatted screenplay pages.

See [Print System Guide](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/11-Print-System.md) for details.

### Can I create custom Prints?

Yes! You can create custom Print templates by writing JSON configuration files.

A visual Print editor is planned for a future release to make this easier.

See [Custom Prints Guide](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/12-Custom-Prints.md) for instructions.

### Can I export Prints to PDF?

Not yet. PDF export is planned for a future release.

**Current workaround:** Take a screenshot of the Print preview.

### Can I edit CSV data directly in the Print preview?

Yes! This is called "bidirectional editing." Click any text in the Print preview to edit it, and changes will immediately update in both the Print view and the CSV grid.

See [Print System Guide](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/11-Print-System.md) for details.

## File Operations

### What CSV delimiter does Juniper support?

Currently, Juniper only supports **comma** (`,`) as the delimiter.

Support for other delimiters (semicolon, tab, pipe) is planned for a future release.

**Workaround:** Convert your file to comma-delimited:
```bash
# Replace semicolons with commas
sed 's/;/,/g' input.csv > output.csv
```

### Does Juniper support Excel (.xlsx) files?

No. Juniper only supports CSV (`.csv`) files.

**Workaround:** Export your Excel file to CSV:
1. In Excel: File → Save As
2. Choose "CSV (Comma delimited)" format
3. Open the CSV in Juniper

### Can I open files from Google Sheets?

Export your Google Sheet to CSV first:
1. In Google Sheets: File → Download → Comma-separated values (.csv)
2. Open the downloaded CSV in Juniper

### Does Juniper support TSV (tab-separated) files?

Not yet. TSV support is planned for a future release.

**Workaround:** Convert TSV to CSV:
```bash
# Replace tabs with commas
sed 's/\t/,/g' input.tsv > output.csv
```

### Can I drag and drop files to open them?

Yes! Drag a CSV file from your file manager and drop it onto the Juniper window to open it.

## Editing

### How do I delete a row?

Row deletion is planned for a future update.

**Workaround:** Select all cells in the row and delete their contents (delete key), then save. This leaves an empty row that you can ignore or remove in a text editor.

### How do I delete a column?

Column deletion is planned for a future update.

**Workaround:** Open the CSV in a text editor and manually remove the column.

### Can I reorder rows and columns?

Yes!

**Rows:** Click and drag the row number on the left side.

**Columns:** Click and drag the column header.

See [CSV Editing Guide](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/10-CSV-Editing-Guide.md) for details.

### Why can't I paste formatted text from Word/Excel?

Juniper pastes as **plain text only**. Formatting (bold, colors, etc.) is not preserved.

This is intentional - CSV is a plain text format and doesn't support formatting.

### Does Juniper have undo/redo?

Yes! Juniper tracks all changes since you opened the file.

- **Undo:** `Ctrl+Z`
- **Redo:** `Ctrl+Shift+Z` or `Ctrl+Y`

Note: Undo history is cleared when you close the file.

## Keyboard Shortcuts

### Can I customize keyboard shortcuts?

Not yet. Custom shortcuts are planned for a future release.

For now, shortcuts are fixed. See [Keyboard Shortcuts Reference](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/20-Keyboard-Shortcuts.md) for the complete list.

### Do shortcuts work on macOS?

Yes, but `Ctrl` becomes `Cmd` (Command key) on macOS.

Example:
- Windows/Linux: `Ctrl+S` to save
- macOS: `Cmd+S` to save

See [Keyboard Shortcuts Reference](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/20-Keyboard-Shortcuts.md) for details.

## Technical

### What technologies is Juniper built with?

- **Tauri 2.0** - Desktop framework (Rust backend)
- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **TailwindCSS + daisyUI** - Styling

See README.md for complete tech stack.

### Is Juniper open-source?

Yes! The source code is available on [GitLab](https://gitlab.com/parkerhdavis/Juniper).

### How can I contribute?

See `wiki-internal/Developer-Guide.md` for development setup and contribution guidelines.

### Why is the installer unsigned?

Code signing certificates are expensive ($300-500/year). As a free, open-source project, we currently don't have code signing.

This means:
- **Windows:** SmartScreen warning (click "More info" → "Run anyway")
- **macOS:** Gatekeeper warning (right-click → "Open")

We plan to add code signing in the future if funding allows.

### Does Juniper collect any data?

**No.** Juniper:
- Does not phone home
- Does not collect telemetry
- Does not track usage
- Does not require an account
- Does not send data anywhere

Your data stays on your computer. Period.

### Where does Juniper store settings and preferences?

**Linux:** `~/.config/juniper/`

**Windows:** `%APPDATA%\juniper\`

**macOS:** `~/Library/Application Support/juniper/`

This includes:
- User preferences
- Custom Print templates
- Recent files list (coming soon)
