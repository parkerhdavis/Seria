# Troubleshooting Guide

Common issues and solutions for Seria users.

---

## Installation Issues

### Linux: "Permission denied" when running AppImage

**Symptom:** Double-clicking the AppImage does nothing, or terminal shows "Permission denied"

**Solution:**
```bash
chmod +x Seria-*.AppImage
./Seria-*.AppImage
```

The AppImage needs execute permission before it can run.

---

### Linux: AppImage won't run - "FUSE error"

**Symptom:** Error message about FUSE or libfuse when launching AppImage

**Solution:** Install FUSE:
```bash
# Ubuntu/Debian
sudo apt install fuse libfuse2

# Fedora
sudo dnf install fuse fuse-libs

# Arch
sudo pacman -S fuse2
```

Then try running the AppImage again.

---

### Windows: SmartScreen blocks installation

**Symptom:** Windows shows "Windows protected your PC" message

**Solution:**
1. Click "More info"
2. Click "Run anyway"

This is normal for unsigned applications. Seria is safe to install.

**Alternative:** Right-click the installer → Properties → Check "Unblock" → OK

---

### macOS: "App cannot be opened" or Gatekeeper error

**Symptom:** macOS blocks Seria with security warning

**Solution:**
1. Right-click `Seria.app` in Applications folder
2. Select "Open"
3. Click "Open" in the security dialog

This only needs to be done once. After that, you can launch normally.

---

### Linux: Missing dependencies for .deb/.rpm package

**Symptom:** Installation fails with dependency errors

**Solution:**
```bash
# Debian/Ubuntu
sudo apt-get install -f

# Fedora
sudo dnf install ./seria-*.rpm

# Will automatically resolve dependencies
```

## File Operations

### Can't open CSV file - "Invalid format" error

**Symptom:** File opens but data is in wrong columns or garbled

**Possible Causes:**
1. **Unsupported delimiter** - File uses semicolons (`;`) or pipes (`|`) instead of commas or tabs
2. **Wrong encoding** - File is not UTF-8
3. **Malformed CSV** - Quotes or commas not properly escaped

**Solutions:**

**1. Check delimiter:**
Open the file in a text editor and look at the first few lines:
```csv
Name,Age,City          ← Commas (CSV - supported)
Name    Age    City    ← Tabs (TSV - supported)
Name;Age;City          ← Semicolons (not supported yet)
Name|Age|City          ← Pipes (not supported yet)
```

Seria currently supports CSV (comma-delimited) and TSV (tab-delimited). Convert other formats:
```bash
# Replace semicolons with commas (Linux/macOS)
sed 's/;/,/g' input.csv > output.csv

# Replace pipes with commas
sed 's/|/,/g' input.txt > output.csv
```

**2. Check encoding:**
```bash
# Check file encoding (Linux)
file -i yourfile.csv

# Convert to UTF-8 if needed
iconv -f ISO-8859-1 -t UTF-8 input.csv > output.csv
```

**3. Validate CSV format:**
- Quoted fields should use double quotes: `"value"`
- Quotes inside fields should be escaped: `"He said ""hello"""`
- All rows should have same number of columns

---

### Changes aren't saving

**Symptom:** Edit cells, click Save, but changes don't persist

**Possible Causes:**
1. File is read-only
2. File location requires admin permissions
3. Disk is full
4. File is open in another program

**Solutions:**

**Check file permissions:**
```bash
# Linux/macOS
ls -l yourfile.csv
# Should show 'w' (write) permission

# Make writable
chmod +w yourfile.csv
```

**Windows:**
Right-click file → Properties → Uncheck "Read-only"

**Check disk space:**
```bash
# Linux/macOS
df -h .

# Windows (PowerShell)
Get-PSDrive C
```

**Close file in other programs:**
- Check if file is open in Excel, LibreOffice, or text editor
- Close other programs and try saving again

---

### Can't find recently opened file

**Symptom:** Want to reopen a file but can't remember location

**Solution:**
1. Click menu (three dots) → Recent Files
2. Or use the file tree sidebar (`Ctrl+.`) to browse

**Note:** Recent files list is planned for a future release.

## Editing Issues

### Can't edit a cell - clicking does nothing

**Symptom:** Clicking or double-clicking cell doesn't start editing

**Possible Causes:**
1. Cell is already selected but not in edit mode
2. Print preview is in edit mode
3. Application is frozen

**Solutions:**

**Try keyboard:** Press `F2` or `Enter` to start editing

**Check Print preview:** Close Print preview panel and try again

**Restart Seria:** If frozen, close and reopen

---

### Paste doesn't work or pastes incorrectly

**Symptom:** `Ctrl+V` doesn't paste, or pastes wrong data

**Possible Causes:**
1. Nothing in clipboard
2. Clipboard data isn't CSV/text
3. Selection is wrong size

**Solutions:**

**Verify clipboard:** Copy from Seria or a text editor (not binary data)

**Check selection:**
- Single cell: Pastes entire copied range starting at that cell
- Multiple cells: Pastes/tiles to fit selection

**Try smaller paste:** Copy just one cell and paste to test

---

### Undo isn't working

**Symptom:** `Ctrl+Z` doesn't undo changes

**Possible Causes:**
1. Already at beginning of undo history
2. Undo history was cleared (file was closed and reopened)
3. Some operations not yet undoable

**Solutions:**

**Check undo history:** Look for undo button state (grayed out = no more undos)

**Operations that are undoable:**
- Cell edits
- Row additions
- Copy/paste
- Find and replace
- Drag and drop

**Not yet undoable:**
- Column additions/deletions
- Some bulk operations

## Display Issues

### Text is cut off or truncated in cells

**Symptom:** Long text in cells is hidden with "..."

**Solutions:**

**1. Resize column:**
- Drag column border to widen column
- Or double-click column border to auto-fit

**2. Enable text wrapping:**
- Toggle "Wrap Text" in toolbar
- Text will wrap to multiple lines in cell

**3. View in Print preview:**
- Print preview shows full text

---

### UI is too small or too large

**Symptom:** Interface is hard to read

**Solutions:**

**Adjust zoom:**
- `Ctrl+=` to zoom in
- `Ctrl+-` to zoom out
- `Ctrl+0` to reset

**Change system DPI:** (affects all apps)
- Windows: Settings → Display → Scale and layout
- macOS: System Preferences → Displays → Resolution
- Linux: Depends on desktop environment

---

### Dark/light theme looks wrong

**Symptom:** Colors are hard to read or ugly

**Solutions:**

**Toggle theme:** Click theme button in toolbar or press `Ctrl+T`

**System theme:** Seria respects your OS theme preference by default

---

### Print preview is blank or shows errors

**Symptom:** Print preview panel is empty or shows "Error"

**Possible Causes:**
1. CSV columns don't match Print template
2. No data rows in CSV
3. Print template is corrupted

**Solutions:**

**Check column names:**
- Print templates require specific column names
- Column names are case-sensitive
- Example: Screenplay Print needs "Element", "Content", "Scene"

**Verify CSV has data:**
- At least one data row (besides header)

**Try different Print template:**
- Switch to another bundled Print
- If others work, the Print template file may be corrupted

---

## Performance Issues

### Application is slow or laggy

**Symptom:** Editing is slow, scrolling is jerky

**Possible Causes:**
1. Very large CSV file (10,000+ rows)
2. Print preview is open
3. Many filters or complex sorts active
4. Low system memory

**Solutions:**

**Close Print preview:** Especially for large files

**Clear filters:** Remove unnecessary column filters

**Disable row coloring:** Turn off alternating/field-based row coloring

**Reduce zoom:** Lower zoom level in CSV grid

**Close other apps:** Free up system memory

**Split large files:** If file is 50,000+ rows, consider splitting into multiple CSVs

---

### Scrolling is jumpy or skips rows

**Symptom:** Scrolling through large CSV jumps around

**Cause:** Virtualization rendering for large datasets

**Solutions:**

**Use keyboard navigation:** Arrow keys for precise movement

**Jump to specific row:** Use "Go to line" feature (coming soon)

**This is normal** for files with 1000+ rows (performance optimization)

## Data Issues

### Sorting produces unexpected results

**Symptom:** Data isn't sorted alphabetically or numerically

**Possible Causes:**
1. Mixed text and numbers in column
2. Leading/trailing spaces
3. Data type misdetection

**Solutions:**

**Clean data first:**
- Remove leading/trailing spaces
- Ensure consistent data types in column

**Numeric sort:** Currently treats all data as text. For proper numeric sorting:
1. Pad numbers with leading zeros: `001`, `002`, `010`
2. Or use external tool to sort numerically first

---

### Filter doesn't find expected rows

**Symptom:** Filter returns no results or wrong results

**Possible Causes:**
1. Filter is case-sensitive
2. Extra spaces in data
3. Wrong filter operation selected

**Solutions:**

**Check filter operation:**
- **Contains (∋)** - Partial match
- **Equals (=)** - Exact match
- **Not contains (!∋)** - Excludes partial match
- **Not equals (!=)** - Excludes exact match

**Check for spaces:** Data may have leading/trailing spaces

**Try wildcard:** Use broader search term

---

### Copied data pastes in wrong format

**Symptom:** Copy from Excel/Sheets, paste into Seria looks wrong

**Cause:** Seria pastes as plain text (doesn't preserve formatting)

**Solutions:**

**Copy as CSV:**
1. In Excel: Save As → CSV
2. Open CSV in Seria
3. Copy/paste within Seria

**Paste into single column:** Paste plain text, then split if needed
