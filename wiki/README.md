## 📝 Documentation Standards

### File Naming

- Use numbered prefixes for ordering: `01-`, `02-`, etc.
- Use descriptive kebab-case names: `csv-editor-architecture.md`
- Group related documents with number ranges:
  - `01-04` - Architecture and design
  - `10-19` - Feature documentation
  - `20-29` - Quick references

### Content Guidelines

**Internal Documentation:**
- Include code examples and architecture diagrams
- Document technical decisions and rationale
- Link to relevant code files with line numbers
- Keep synchronized with code changes

**External Documentation:**
- Use clear, non-technical language
- Include screenshots and visual guides
- Provide step-by-step instructions
- Anticipate user questions and pain points

## 🔧 Maintaining Documentation

- Update documentation when adding or changing features
- Cross-reference related documents
- Keep README.md indices up to date
- Review quarterly for accuracy and completeness
