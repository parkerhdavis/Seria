# Where the Files Are

Juniper stores its settings, configurations, and custom templates locally on your machine. This document explains what data is stored where.

## Storage Locations

**Windows:**
```
%LOCALAPPDATA%\juniper\
```

**macOS:**
```
~/Library/Application Support/juniper/
```

**Linux:**
```
~/.local/share/juniper/
```

## What's Stored

### File Configurations (`file-configs.json`)

Stores per-file settings so your workspace preferences persist across sessions:
- Column widths and auto-fit state
- Active filters
- Display preferences (text wrapping, separators, row coloring)
- Print drawer position

See [File and Global Configs](../03%20-%20Customization/03.03%20-%20File%20and%20Global%20Configs.md) for details.

### User Preferences (`preferences.json`)

Application-wide settings:
- Theme preference (light, dark, auto)
- Window state and position
- Recent files list
- Global display preferences

### Custom Print Recipes (`prints/*.json`)

Your custom Print templates created with the Recipe editor. Bundled recipes (Screenplay, Dialogue, etc.) are part of the app and don't live here.

### Print Recipe Storage (Browser localStorage)

Print recipe configurations and field mappings stored in browser localStorage under `juniper-print-recipe-storage`.

**Note:** This is stored in browser storage, not in files. Clearing browser data will erase these configurations.

## Backup and Portability

### Manual Backup

1. Navigate to your app data directory (see locations above)
2. Copy the entire `juniper/` folder to a backup location
3. For Print Recipe Storage, use **Export Configs** in Settings

### Moving to a New Machine

**Same OS:**
1. Export file configs (Settings ’ Export Configs)
2. Copy `prints/` directory (custom templates)
3. Copy `preferences.json` (global settings)
4. Import on new machine

**Different OS:**
- File paths won't match, but content hashes will
- Export configs, move CSV files, open on new machine, then import

## Privacy Note

Stored data may include file paths showing your folder structure. Review before sharing exported configs.

## Clearing Storage

**Reset to defaults:**
1. Close Juniper
2. Navigate to app data directory
3. Delete `juniper/` folder
4. Restart Juniper

**Clear just file configs:**
- Settings ’ File Configuration Management ’ Cleanup Old Configs
