# Developer Quick Start

This guide will get you up and running with Seria development in minutes.

## Clone the Repository

```bash
git clone <repository-url>
cd Seria
```

## Setup

Run the automated setup script to check dependencies and configure your environment:

```bash
./setup.sh
# OR
make setup
```

The setup script automatically detects your OS (Linux, macOS, or Windows via Git Bash/WSL) and verifies:
- Rust toolchain
- Node.js 18+
- Platform-specific system dependencies
- Windows cross-compilation tools (Linux/macOS only)

If any dependencies are missing, the script provides clear installation instructions.

## Development

Start the development server with hot-reload for both React and Rust:

```bash
make dev
# OR
cd frontend && npm run tauri:dev
```

This will launch the Seria desktop application with live reloading enabled.

## Build

Create production installers for your platform:

```bash
make build        # Build for all platforms (Linux + Windows)
make build-linux  # Linux only (.deb, .rpm, AppImage)
make build-windows # Windows only (.exe, .msi)
```

Build output is located in `target/release/bundle/` (Linux) or `target/x86_64-pc-windows-msvc/release/bundle/` (Windows).
