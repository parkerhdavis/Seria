## Technical Changes

- Removed `target/README.md` and `target/upload-to-gitlab.sh` from version control; removed their `.gitignore` exceptions so `target/` is now fully ignored
- **Replaced Vite with Bun's native bundler and Tailwind CLI** — eliminates Vite, Vitest, PostCSS, and autoprefixer from the dependency tree. Production builds use `Bun.build()` via `build.ts`; development uses a custom Bun dev server (`dev.ts`) with WebSocket live-reload. Tests now run via `bun test` instead of Vitest. CSS is processed by the standalone Tailwind CLI rather than PostCSS.
- **Migrated from Tauri to Electrobun** — Seria is now a single-runtime Bun application. The entire Rust backend (file_ops, storage, screenplay converter, CSV diff) was ported to TypeScript and runs under Bun as the main process. All 16 former Tauri commands become typed RPC methods shared between main and renderer, with thin wrappers preserving the `@tauri-apps/plugin-*` surface (dialog, clipboard, fs, path, window) so renderer code only changes import paths. The React/Zustand tree moved from `frontend/src/` to `src/mainview/`; `backend/`, `scripts/sync-version.*`, and the Tauri CLI dependencies are gone. Bundle is packaged via `bunx electrobun build`; view bundle is produced by `Bun.build()` in HTML-entrypoint mode with `bun-plugin-tailwind`. Storage location (`~/.config/seria/` on Linux, equivalents on macOS/Windows) is unchanged so existing preferences, file-configs, workspaces, and custom prints load without migration.
