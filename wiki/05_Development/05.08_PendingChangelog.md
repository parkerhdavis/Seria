## Technical Changes

- **Makefile convention migration.** Brought the Makefile into line with the portfolio Makefile conventions: `# ─── Section ───` dividers, `BACKEND` / `FRONTEND` path variables, header banner, and `## comment` + grep-driven `make help`. The dev recipe no longer launches the frontend itself — Tauri now spawns it via `beforeDevCommand` in `tauri.conf.json` — and `make down` reduces to a port pre-flight on `:5173` (no more `.dev.pid` file).
