## Technical Changes

- **Makefile convention migration.** Brought the Makefile into line with the portfolio Makefile conventions: `# ─── Section ───` dividers, `BACKEND` / `FRONTEND` path variables, header banner, and `## comment` + grep-driven `make help`. The dev recipe no longer launches the frontend itself — Tauri now spawns it via `beforeDevCommand` in `tauri.conf.json` — and `make down` reduces to a port pre-flight on `:5173` (no more `.dev.pid` file).
- **Relicense from GPL-3.0 to AGPL-3.0-or-later.** Replaced `LICENSE.md` with the verbatim AGPL-3.0 text, declared `AGPL-3.0-or-later` as the SPDX identifier in `Cargo.toml` and both `package.json` files, set `bundle.licenseFile` in `tauri.conf.json`, and added `SPDX-License-Identifier: AGPL-3.0-or-later` headers to all project-authored source files. README and Contributing guide updated to reference AGPL.
