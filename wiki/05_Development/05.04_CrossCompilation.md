# Platform-Specific Builds

This guide describes how to build Seria for different platforms using native builds on each operating system.

---

## Overview

Seria builds platform-specific installers natively on each operating system:

- **Linux** builds Linux installers (AppImage, .deb, .rpm)
- **Windows** builds Windows installers (.msi, .exe)
- **macOS** builds macOS installers (.dmg, .app)

This approach ensures full compatibility with platform-specific tools and produces complete installers with all features.

---

## Prerequisites

### All Platforms

**Required:**
- Node.js 18+
- Rust (via rustup)
- Git

### Linux

Install Tauri dependencies on Ubuntu/Debian:

```bash
sudo apt install libwebkit2gtk-4.1-dev \
    build-essential \
    curl \
    wget \
    file \
    libssl-dev \
    libgtk-3-dev \
    libayatana-appindicator3-dev \
    librsvg2-dev
```

Or run `make setup` which will check for missing dependencies.

### Windows

**Required:**
- Visual Studio C++ Build Tools (installed automatically with Rust)
- WebView2 Runtime (usually pre-installed on Windows 10/11)

For detailed instructions, see:
https://tauri.app/v2/guides/prerequisites/#windows

### macOS

**Required:**
- Xcode Command Line Tools: `xcode-select --install`
- Homebrew (recommended): https://brew.sh

---

## Building

### Quick Start

On any platform:

```bash
# Install dependencies
make setup

# Build for current platform
make build
```

The `make build` command automatically detects your operating system and runs the appropriate build.

### Platform-Specific Commands

```bash
# Linux only
make build-linux

# Windows only
make build-windows

# macOS only
make build-macos
```

## Output Location

All builds output to `target/release/bundle/` with platform-specific subdirectories.

### Linux

```
target/release/bundle/
├── appimage/
│   └── seria_0.0.1_amd64.AppImage
├── deb/
│   └── seria_0.0.1_amd64.deb
└── rpm/
    └── seria-0.0.1-1.x86_64.rpm
```

### Windows

```
target/release/bundle/
├── msi/
│   └── Seria_0.0.1_x64_en-US.msi
└── nsis/
    └── Seria_0.0.1_x64-setup.exe
```

### macOS

```
target/release/bundle/
├── dmg/
│   └── Seria_0.0.1_x64.dmg
└── macos/
    └── Seria.app
```

See `target/README.md` for complete details on build output locations.

## Multi-Platform Release Workflow

To create releases for all platforms:

1. **On Linux:**
   ```bash
   make build
   ```
   Produces: AppImage, .deb, .rpm

2. **On Windows:**
   ```bash
   make build
   ```
   Produces: .msi, .exe (NSIS installer)

3. **On macOS:**
   ```bash
   make build
   ```
   Produces: .dmg, .app

4. **Upload all artifacts** to your release (GitLab, GitHub, etc.)

### CI/CD Automation

For automated multi-platform builds, use CI/CD runners on each platform:

- **Linux:** GitLab shared runners (Docker)
- **Windows:** Self-hosted runner with `windows` tag
- **macOS:** Self-hosted runner with `macos` tag

See `wiki/05_Development/05.03_BuildingAndDistribution.md` for CI/CD pipeline details.

## Troubleshooting

### Build Fails with Missing Dependencies

Run `make setup` to check for and install missing dependencies.

### "Tauri command not found"

The Tauri CLI is installed as a dev dependency:

```bash
cd frontend && npm install
```

### WebView2 not found (Windows)

Download and install from [Microsoft WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

### webkit2gtk not found (Linux)

```bash
# Ubuntu/Debian
sudo apt install libwebkit2gtk-4.1-dev

# Fedora
sudo dnf install webkit2gtk4.1-devel

# Arch
sudo pacman -S webkit2gtk
```

## Testing Builds

Always test installers on clean machines before distribution:

- **Linux:** Test on a fresh Ubuntu/Fedora VM or container
- **Windows:** Test on a clean Windows installation
- **macOS:** Test on a fresh macOS installation

This catches dependency issues that may not appear on development machines.
