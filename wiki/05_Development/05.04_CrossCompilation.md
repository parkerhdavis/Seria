# Cross-Compilation for Windows Builds

This guide describes how to build Windows executables (.exe/.msi installers) from a Linux development machine using cross-compilation.

---

## Overview

Seria uses **cargo-xwin** to cross-compile Rust code from Linux to Windows MSVC targets. This allows you to create Windows executables (.exe) without needing a Windows machine or VM.

**Important Limitation:** While cargo-xwin can build the Windows `.exe` binary from Linux, creating Windows installers (`.msi` and `.exe` installers via NSIS) requires Windows-specific bundling tools (WiX, NSIS) that only work on Windows. Cross-compilation from Linux produces a fully functional `seria.exe` binary that can be distributed directly, but installer creation must be done on a Windows machine.

---

## Prerequisites

The following tools must be installed on your Linux system:

1. **Rust toolchain** (via rustup)
2. **Windows MSVC target** for Rust
3. **cargo-xwin** - Cross-compilation tool
4. **LLVM, lld, and clang** - Required for Windows cross-compilation
   - `llvm-rc` - Embeds icons and metadata into Windows executables
   - `lld` - LLVM linker for linking Windows binaries
   - `clang` - C/C++ compiler used by cargo-xwin for building native dependencies

## Setup (One-time)

These steps have already been completed for this project, but are documented here for reference:

### 1. Install System Dependencies

On Ubuntu/Debian, install LLVM, lld, and clang:

```bash
sudo apt install llvm lld clang
```

**Why this is needed:**
- `llvm-rc` (LLVM Resource Compiler) - Embeds icons and metadata into Windows executables
- `lld` - LLVM linker, used by cargo-xwin for linking Windows binaries
- `clang` - C/C++ compiler used by cargo-xwin to compile native dependencies for Windows

**Note:** Running `make setup` or `./setup.sh` will check for these dependencies and warn if they're missing.

### 2. Add Windows Rust Target

```bash
rustup target add x86_64-pc-windows-msvc
```

This downloads the standard library compiled for Windows MSVC.

### 3. Install cargo-xwin

```bash
cargo install cargo-xwin
```

cargo-xwin handles linking and provides Windows SDK libraries without requiring an actual Windows installation.

### 4. Configure Build System

No additional configuration is required. The Makefile handles the Windows build process using a two-step approach:

1. **Build the Rust binary** using cargo-xwin directly:
   ```bash
   cargo xwin build --release --target x86_64-pc-windows-msvc
   ```

2. **Bundle into installers** using Tauri CLI:
   ```bash
   tauri build --bundles msi,nsis --target x86_64-pc-windows-msvc --ci
   ```

The `--ci` flag tells Tauri to skip rebuilding and just package the already-built binary.

**Important:** Do NOT configure cargo-xwin as a linker in `.cargo/config.toml`. It's invoked directly as a cargo subcommand.

## Building

Once the setup is complete, you can build installers using Make commands:

### Build All Platforms

```bash
make build
```

This builds for **both Linux and Windows**, creating installers for all supported platforms.

### Build Windows Only

```bash
make build-windows
```

### Build Linux Only

```bash
make build-linux
```

### Using npm (alternative)

From the frontend directory, you can also use npm scripts:

```bash
cd frontend
npm run tauri:build:windows    # Windows only
npm run tauri:build             # Linux only
```

The build process will:
1. Build the frontend (React + Vite)
2. Cross-compile the Rust backend for the target platform(s)
3. Package everything into platform-specific installers

## Output Location

Build artifacts are placed in the **top-level `target/` directory** (not `backend/target/`). See [Project Quirks](05.06_ProjectQuirks.md) for details on this non-standard directory structure.

**Linux builds:**
```
target/release/bundle/
├── appimage/
│   └── seria_0.0.1_amd64.AppImage
├── deb/
│   └── seria_0.0.1_amd64.deb
└── rpm/
    └── seria-0.0.1-1.x86_64.rpm
```

**Windows builds (from Linux):**
```
target/x86_64-pc-windows-msvc/release/
└── seria.exe          # Fully functional Windows executable
```

**Note:** When built from Linux, only the `.exe` binary is created. Windows installer formats (`.msi`, NSIS `.exe` installer) can only be created on Windows systems due to platform-specific bundling tool requirements.

**Windows builds (from Windows):**
```
target/release/bundle/
├── msi/
│   └── Seria_0.0.1_x64_en-US.msi
└── nsis/
    └── Seria_0.0.1_x64-setup.exe
```

See `target/README.md` for complete details on build output locations.

## How It Works

The Windows cross-compilation process from Linux:

1. **cargo-xwin** is invoked as a cargo subcommand: `cargo xwin build`
2. On first run, cargo-xwin automatically downloads necessary Windows SDK components (this may take a few minutes)
3. The SDK is cached in `~/.xwin/` for future builds
4. Rust code is compiled for the `x86_64-pc-windows-msvc` target using the downloaded Windows SDK
5. The compiled binary is output to `target/x86_64-pc-windows-msvc/release/seria.exe`

**Creating Windows Installers:**

Windows installer formats (`.msi` via WiX, `.exe` via NSIS) require Windows-specific bundling tools that cannot run on Linux. To create installers:

1. Transfer the project to a Windows machine (or use the seria.exe binary directly)
2. Run `npm run tauri:build` from the frontend directory on Windows
3. Installers will be created in `target/release/bundle/`

The `seria.exe` binary produced by cross-compilation is fully functional and can be distributed directly without an installer.

## Troubleshooting

### Build Fails with Missing Compiler Tools

**Error: `llvm-rc not found`**

If you see an error like `called Result::unwrap() on an Err value: NotAttempted("llvm-rc")`, you need to install LLVM:

```bash
sudo apt install llvm lld clang
```

**Error: `clang-cl not found` or `failed to find tool "clang-cl"`**

If you see errors about missing `clang-cl`, you need to install the clang compiler:

```bash
sudo apt install clang
```

**Why these are needed:**
- `llvm-rc` - Embeds icons and metadata into Windows .exe files
- `lld` - LLVM linker for Windows targets
- `clang` (provides `clang-cl`) - C/C++ compiler used to build native dependencies for Windows

**Note:** Running `./setup.sh` will automatically check for these dependencies.

### Build Fails with Linker Errors

If you see linker errors, ensure cargo-xwin is properly installed:

```bash
cargo install --force cargo-xwin
```

### Missing Windows SDK Components

cargo-xwin should automatically download required SDK components on first build. This may take a few minutes and requires internet connectivity.

### Tauri CLI Not Found

If the build fails with "tauri command not found", ensure you've run:

```bash
cd frontend && npm install
```

## Testing Windows Builds

To test the generated Windows installers:

1. Transfer the `.exe` or `.msi` file to a Windows machine
2. Run the installer
3. Test the application functionality

**Note:** Cross-compiled builds should be tested on actual Windows systems before distribution, as some runtime issues may only appear on the target platform.
