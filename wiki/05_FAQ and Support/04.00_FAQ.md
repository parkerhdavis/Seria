# Frequently Asked Questions

Common questions about Seria.

---

## General

### What is Seria?

Seria is a specialized desktop CSV editor designed for writers and designers who use CSV data in creative workflows. It combines spreadsheet-like editing with professional document previews (called "Prints") that format your CSV data into polished page layouts.

### Is Seria free and/or open-source?

Yep, Seria is free and open-source software. After quite a few years of game dev and a skosh of web dev, it's actually my first open-source app. So your consideration is appreciated and your feedback is welcome.

### What platforms does Seria support?

Seria runs on:
- **Linux** (Ubuntu, Fedora, Arch, and most modern distributions)
- **Windows** (Windows 10 version 1809 and later)
- **macOS** (macOS 10.15 Catalina and later)

### How is Seria different from Excel or Google Sheets?

To start: I'd never try to replace Excel or Sheets. I love data and those are my babies. Seria isn't meant to be a replacement for what spreadsheet applications are best at, but rather to fill a niche where they're not ideal but there's not a great alternative for creatives.

**Seria has:**
- Print system for professional document formats
- Bidirectional editing (edit data in formatted preview)
- Fast, lightweight desktop app
- Focused feature set for narrative and design data

**Seria doesn't have:**
- Cellular formulas or calculations
	- *though we do have columnar formulas/validations*
- As many charts and graphs
	- *though we do have a [Graph Recipe](wiki/03_Print%20View/02.05_Graph%20Recipe.md) with a limited set of visualizations*
- Pivot tables
- Financial functions
- Cloud sync

See [About Seria](wiki/01_Introduction/00.01_About%20Seria.md) for more details.

### Why CSV/TSV and not Excel (.xlsx) format?

CSV and TSV are:
- **Simple** - Plain text format, human-readable
- **Universal** - Supported by every tool
- **Version control friendly** - Works great with Git
- **Lightweight** - No bloat from formatting/formulas

Seria focuses on structured data, not spreadsheet calculations, so CSV/TSV are a perfect fit. JSON support is also planned.

## Features

### Can I edit column headers?

Yes! Column headers are editable just like regular cells. Double-click a header to edit it.

### Can I add/delete rows and columns?

**Rows:**
- ✅ Add rows: `Ctrl+Enter` or right-click → Insert Row
- ⏳ Delete rows: Coming in a future update

**Columns:**
- ✅ Add columns: Right-click → Insert Column Left/Right
- ⏳ Delete columns: Coming in a future update

### Does Seria support formulas or calculations?

No. Seria is designed for creative data (dialogue, story beats, game items), not financial calculations.

If you need calculations, use Excel or Google Sheets to compute values, then export to CSV and open in Seria.

### Can I work with multiple CSV files at once?

Not yet. Seria currently supports one file at a time. Multiple file support is planned for a future release.

**Workaround:** Open multiple Seria windows (launch the app multiple times).

### How large of a CSV can Seria handle?

Here's what I've tested so far:

- **Less than 1,000 rows:** Excellent performance, no issues
- **More than 1,000 rows:** Currently some bugs in the cellular editor that need fixing (should be fixed soon)

### Does Seria auto-save?

Yes. Seria automatically saves your changes after you finish editing cells. Autosave is **enabled by default** with a 30-second timer.

**How it works:**
- After you confirm a cell edit (press Enter, Tab, or click away), the autosave timer starts
- If you make another edit before the timer expires, the timer resets
- When the timer reaches zero, your file is automatically saved
- You can see save confirmations in the developer console

**Configure autosave:**
1. Press `Ctrl+,` to open Settings
2. Go to the **File Saving** section
3. Toggle autosave on/off or adjust the interval (5 seconds to 5 minutes)

**Best practice:** While autosave protects your work, you can still manually save with `Ctrl+S` anytime for important checkpoints.

**Working with version control?** If you prefer manual control over when changes are committed to disk (e.g., for Git workflows), you can disable autosave in Settings and save manually with `Ctrl+S`.

## Print System

### What are "Prints"?

Prints are customizable preview formats that display your CSV data as professional documents. For example, a Screenplay Print transforms dialogue CSV data into properly formatted screenplay pages.

See [Print System Guide](wiki/03_Print%20View/02.00_The%20Print%20View.md) for details.

### Can I create custom Prints?

Yes! You can create custom Print templates by writing JSON configuration files.

A visual Print editor is planned for a future release to make this easier.

See [Custom Prints Guide](wiki/04_Customization/03.04_Custom%20Recipes.md) for instructions.

### Can I export Prints to PDF?

Not yet. PDF export is planned for a future release.

**Current workaround:** Take a screenshot of the Print preview.

### Can I edit CSV data directly in the Print preview?

Yes! This is called "bidirectional editing." Click any text in the Print preview to edit it, and changes will immediately update in both the Print view and the CSV grid.

See [Print System Guide](wiki/03_Print%20View/02.00_The%20Print%20View.md) for details.

## File Operations

### What file formats and delimiters does Seria support?

Seria currently supports:
- **CSV** (comma-separated: `,`)
- **TSV** (tab-separated)

**Coming soon:** JSON support

Support for other delimiters (semicolon `;`, pipe `|`) is planned for a future release.

**Workaround for unsupported delimiters:** Convert your file:
```bash
# Replace semicolons with commas
sed 's/;/,/g' input.csv > output.csv

# Replace pipes with commas
sed 's/|/,/g' input.txt > output.csv
```

### Does Seria support Excel (.xlsx) files?

No. Seria only supports CSV (`.csv`) and TSV (`.tsv`) files.

**Workaround:** Export your Excel file to CSV or TSV:
1. In Excel: File → Save As
2. Choose "CSV (Comma delimited)" or "Text (Tab delimited)" format
3. Open the file in Seria

### Can I open files from Google Sheets?

Yes! Export your Google Sheet to CSV or TSV:
1. In Google Sheets: File → Download → Comma-separated values (.csv) or Tab-separated values (.tsv)
2. Open the downloaded file in Seria

### Does Seria support TSV (tab-separated) files?

Yes! Seria fully supports TSV files. Just open them like you would a CSV file.

### Can I drag and drop files to open them?

Yes! Drag a CSV or TSV file from your file manager and drop it onto the Seria window to open it.

## Editing

### How do I delete a row?

Row deletion is planned for a future update.

**Workaround:** Select all cells in the row and delete their contents (delete key), then save. This leaves an empty row that you can ignore or remove in a text editor.

### How do I delete a column?

Column deletion is planned for a future update.

**Workaround:** Open the CSV in a text editor and manually remove the column.

### Can I reorder rows and columns?

Yes!

**Rows:** Click and drag the row number on the left side.

**Columns:** Click and drag the column header.

See [CSV Editing Guide](wiki/02_Cell%20View/01.04_Cell%20Actions.md) for details.

### Why can't I paste formatted text from Word/Excel?

Seria pastes as **plain text only**. Formatting (bold, colors, etc.) is not preserved.

This is intentional - CSV is a plain text format and doesn't support formatting.

### Does Seria have undo/redo?

Of course, I'm not a monster. Seria tracks all changes since you opened the file.

- **Undo:** `Ctrl+Z`
- **Redo:** `Ctrl+Shift+Z` or `Ctrl+Y`

Note: Undo history is cleared when you close the file.

## Technical

### What technologies is Seria built with?

- **Tauri 2.0** - Desktop framework (Rust backend)
- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool
- **TailwindCSS + daisyUI** - Styling

See README.md for complete tech stack.

### Is Seria open-source?

Yes! The source code is available on [GitLab](https://gitlab.com/parkerhdavis/Seria).

### How can I contribute?

See `wiki-internal/Developer-Guide.md` for development setup and contribution guidelines.

### Why is the installer unsigned?

Code signing certificates are expensive ($300-500/year). As a free, open-source project, we currently don't have code signing.

This means:
- **Windows:** SmartScreen warning (click "More info" → "Run anyway")
- **macOS:** Gatekeeper warning (right-click → "Open")

We plan to add code signing in the future if funding allows.

### Does Seria collect any data?

**No.** Seria:
- Does not phone home
- Does not collect telemetry
- Does not track usage
- Does not require an account
- Does not send data anywhere

Your data stays on your computer. Period.

### Where does Seria store settings and preferences?

**Linux:** `~/.config/seria/`

**Windows:** `%APPDATA%\seria\`

**macOS:** `~/Library/Application Support/seria/`

This includes:
- User preferences
- Custom Print templates
- Recent files list (coming soon)
