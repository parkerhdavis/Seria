# Roadmap

Seria is under active development. This roadmap outlines planned features and improvements. Priorities may shift based on user feedback and technical considerations.

---

## Current Focus (Near-Term)

These features are actively being worked on or are next in the queue:

### Performance Optimization for Large Files

**Status:** In progress

**Goal:** Smooth editing for CSVs with 1,000+ rows

**Includes:**
- Improved virtualization for grid rendering
- Optimized filtering and sorting
- Lazy loading for Print views
- Better memory management

**Expected:** Next release

---

### Row and Column Deletion

**Status:** Planned for next release

**What:**
- Delete rows with keyboard shortcut (`Ctrl+Shift+K`)
- Delete columns with keyboard shortcut (`Ctrl+Shift+D`)
- Right-click context menu options
- Undo support

**Why:** Currently you can add rows/columns but not delete them. This is a frequently requested feature.

---

### PDF Export for Print Views

**Status:** In progress

**What:**
- Export Print views to PDF files
- Preserve formatting, fonts, and layout
- Options for page size, margins, headers/footers
- Batch export multiple Print views

**Use cases:**
- Share formatted scripts with team
- Print physical copies
- Archive formatted versions

**Expected:** Within 2-3 releases

---

## Medium-Term (Next 3-6 Months)

### JSON File Support

**Status:** Planned

**What:**
- Open and edit JSON files in Cell View
- Flatten nested structures for editing
- Save back to valid JSON format
- Print recipes for JSON data

**Why:** Many game engines use JSON for data. This makes Seria useful for more workflows.

---

### Column Formulas and Validation

**Status:** Design phase

**What:**
- Define validation rules per column (e.g., "must be a number")
- Auto-populate columns with formulas (e.g., "FullName = FirstName + LastName")
- Save rules globally or per-file
- Visual feedback for invalid data

**Use cases:**
- Ensure data quality
- Reduce manual data entry
- Catch errors early

---

### Visual Print Recipe Editor

**Status:** Planned

**What:**
- Drag-and-drop interface for creating Print recipes
- Live preview while designing
- No JSON editing required
- Templates and presets

**Why:** Currently you need to manually write JSON to create custom Prints. A visual editor makes this accessible to non-technical users.

---

### Multiple File Support (Tabs)

**Status:** Planned

**What:**
- Open multiple CSV files in tabs
- Switch between files quickly
- Copy/paste between files
- Independent settings per file

**Workaround until then:** Launch multiple Seria windows

---

### Find in All Files

**Status:** Planned

**What:**
- Search across all CSV files in a directory
- View results with file name and context
- Jump to matches in files
- Support for regex patterns

---

## Long-Term (6+ Months)

### Interface Recipe (Custom UI Builder)

**Status:** Early design

**What:** Visual form builder for creating custom UIs for CSV data

See [Interface Recipe](wiki/03_Print%20View/02.07_Interface%20Recipe.md) for full details.

**Why:** Bridge the gap between raw CSV and game/app interfaces.

---

### Custom Keyboard Shortcuts

**Status:** Planned

**What:**
- Rebind existing shortcuts
- Create custom shortcuts for common actions
- Import/export shortcut profiles
- Per-file shortcut overrides (if needed)

---

### Plugin System

**Status:** Under consideration

**What:**
- Third-party extensions
- Custom export formats
- Integration with external tools (Unity, Unreal, Git, etc.)
- Community marketplace for plugins

**Challenges:**
- Security (sandboxing plugins)
- API stability
- Maintenance burden

**Decision pending:** Need to validate demand before committing to this.

---

### Collaborative Editing

**Status:** Future consideration

**What:**
- Real-time collaborative editing
- Cloud sync (optional)
- Comments and change tracking
- Conflict resolution

**Challenges:**
- Seria is designed as a local-first tool
- Adding cloud features contradicts privacy goals
- Complexity of real-time sync

**Alternative approach:** Focus on improving Git-based workflows (diff visualization, merge helpers) instead of building cloud sync.

---

### Additional Delimiter Support

**Status:** Planned

**What:**
- Semicolon-separated (`;`)
- Pipe-separated (`|`)
- Custom delimiters
- Auto-detect delimiter on file open

**Workaround:** Use `sed` to convert to CSV/TSV

---

### Mobile App

**Status:** Not planned

**Why:** Seria is designed for desktop workflows with keyboard shortcuts and precise editing. Mobile form factor doesn't align with the app's goals.

**Alternative:** Seria files (CSV, TSV, JSON) can be edited in mobile text editors or spreadsheet apps if needed.

## Not Planned

These features are explicitly **not** on the roadmap:

### Cell Formulas (Excel-style)

**Why not:** Seria is for content editing, not calculations. Use Excel/Sheets for formulas, then export to CSV for Seria.

**Alternative:** Column-level formulas (planned) provide basic auto-population without the complexity of cell formulas.

---

### Pivot Tables

**Why not:** Outside Seria's scope. Use dedicated data analysis tools.

---

### Real-Time Cloud Sync

**Why not:** Contradicts Seria's local-first, privacy-focused design.

**Alternative:** Use Git or file sync tools (Dropbox, Syncthing) for async collaboration.

---

### Web Version

**Why not:** Seria is a desktop app. Web version would compromise performance and features.

**Note:** Seria files (CSV, TSV) can be opened in any text editor or spreadsheet tool, including web-based ones.

## Development Philosophy

Seria's development is guided by these principles:

1. **Local-first** - Your data stays on your computer
2. **Privacy-focused** - No telemetry, no tracking
3. **Lightweight** - Fast, efficient, minimal bloat
4. **Writer-friendly** - Optimize for content creators, not data scientists
5. **Git-friendly** - Plain text formats that work with version control
6. **Open-source** - Transparent development, community-driven

These principles inform what features get prioritized and how they're implemented.
