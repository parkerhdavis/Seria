# Customizing Seria

Seria offers multiple levels of customization to adapt the app to your workflow, preferences, and specific project needs. This guide provides an overview of what you can customize and where to find the settings.

---

## Types of Customization

Seria supports three levels of customization:

### 1. Basic App Settings

**What:** User preferences that affect how Seria looks and behaves.

**Examples:**
- Theme (light/dark mode)
- Font size and zoom level
- Auto-save interval
- Default file locations

**Where:** Settings dialog (`Ctrl+,`)

**Scope:** Global - applies to all files

See [Basic App Settings](03.01%20-%20Basic%20App%20Settings.md) for details.

---

### 2. File-Specific Configurations

**What:** Settings that are saved per-file, so different CSVs can have different configurations.

**Examples:**
- Column widths and visibility
- Sort and filter state
- Active Print template
- Grid zoom level

**Where:** Automatically saved as you work

**Scope:** Per-file - each CSV remembers its own settings

See [File and Global Configs](03.03%20-%20File%20and%20Global%20Configs.md) for details.

---

### 3. Custom Print Recipes

**What:** Create your own Print templates to display CSV data in custom formats.

**Examples:**
- Custom screenplay format variations
- Game-specific item cards
- Quest log layouts
- Character sheet designs

**Where:** Print template editor or JSON files

**Scope:** Can be global (shared across files) or file-specific

See [Custom Recipes](03.04%20-%20Custom%20Recipes.md) for details.

---

## File-Specific vs. Global Settings

Seria uses two types of configuration storage:

### File-Specific Settings

**Saved:** Per-file, in `~/.config/seria/file-configs/` (or equivalent)

**Includes:**
- Column widths, visibility, order
- Active filters and sort state
- Selected Print template
- Grid zoom level
- Last cursor position

**Why per-file?** Different CSVs have different structures and needs. A dialogue CSV might use Screenplay print, while an item CSV uses Record print.

### Global Settings

**Saved:** User-wide, in `~/.config/seria/preferences.json` (or equivalent)

**Includes:**
- Theme preference
- Default font size
- Auto-save settings
- Custom Print templates (shared)
- Recent files list (coming soon)

**Why global?** Personal preferences that should apply everywhere.

## Resetting to Defaults

**To reset all settings:**
1. Close Seria
2. Delete (or rename) the Seria config directory:
   - **Linux:** `~/.config/seria/`
   - **Windows:** `%APPDATA%\seria\`
   - **macOS:** `~/Library/Application Support/seria/`
3. Restart Seria - fresh defaults will be created

**To reset per-file settings:**
1. Delete the specific file's config from `~/.config/seria/file-configs/` (or equivalent)
2. Reopen the CSV - default settings will apply

## Tips for Customizing

**Start simple:**
- Use built-in settings before creating custom recipes
- Try different Print templates to find what works
- Adjust one setting at a time

**Experiment with file-specific configs:**
- Set up one CSV exactly how you like it
- Notice which settings are remembered
- Apply similar configurations to similar CSVs

**Share with your team:**
- Export custom Print recipes as JSON
- Share config files for consistent team setup
- Document custom workflows in project README

**Keep a backup:**
- Copy your config directory before major changes
- Export custom recipes you spent time creating
- Document custom settings for future reference

## Configuration Files

Seria stores configuration in these locations:

### Linux
```
~/.config/seria/
├── preferences.json          # Global settings
├── file-configs/             # Per-file settings
│   └── [file-hash].json
├── prints/                   # Custom Print templates
│   └── custom-recipe.json
└── recent-files.json         # Recent files (coming soon)
```

### Windows
```
%APPDATA%\seria\
├── preferences.json
├── file-configs\
├── prints\
└── recent-files.json
```

### macOS
```
~/Library/Application Support/seria/
├── preferences.json
├── file-configs/
├── prints/
└── recent-files.json
```

See [Where the Files Are](../00%20-%20Introduction/00.04%20-%20Where%20the%20Files%20Are.md) for details.
