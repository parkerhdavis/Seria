# Interface Recipe

The **Interface Recipe** is an upcoming feature currently in development that will allow you to design custom visual interfaces for viewing and editing your CSV data. Think of it as a visual form builder that transforms your raw CSV into custom-designed UI screens.

---

## What It Will Be

The Interface Recipe will let you:
- **Design custom UIs** - Create visual layouts for your data
- **Build forms** - Define input fields, dropdowns, checkboxes
- **Preview interfaces** - See data in custom-designed screens
- **Edit visually** - Interact with your CSV through the designed interface

**Example use cases:**
- Character creation screen (RPG-style interface)
- Item shop interface (merchant inventory view)
- Quest tracker UI (game-style quest log)
- Dialogue editor (conversation tree view)

---

## Why It's Useful

Traditional CSV editing is functional but not always intuitive. The Interface Recipe will bridge the gap between raw data and game/app UIs:

**Current workflow:**
- Edit data in spreadsheet grid
- Imagine how it will look in game
- Import to game engine to test
- Go back to CSV to make changes

**With Interface Recipe:**
- Design interface that matches your game UI
- Edit data directly in the interface
- See exactly how it will look
- CSV updates automatically

---

## Planned Features

### Visual Form Designer

**Drag-and-drop editor for creating interfaces:**
- Place input fields, labels, buttons
- Configure field types (text, number, dropdown, checkbox)
- Map fields to CSV columns
- Design layout and spacing

### Multiple Interface Views

**Create different interfaces for the same CSV:**
- "Edit view" with all fields
- "Preview view" with formatted read-only layout
- "Compact view" with only essential fields
- Switch between views based on task

### Interactive Elements

**Planned interactive components:**
- Dropdowns populated from CSV values
- Image previews (for file paths in CSV)
- Color pickers (for hex color columns)
- Relationship links (click to jump to related records)

### Templates

**Pre-built interface templates:**
- Character sheet template
- Item card template
- Quest log template
- Dialogue node template
- Custom template creator

## How It Will Work (Planned)

### Step 1: Create Interface

1. Open Interface Recipe designer
2. Select CSV columns to include
3. Drag fields onto canvas
4. Configure field types and labels
5. Design layout

### Step 2: Map Data

1. Map each interface field to a CSV column
2. Define field behavior (required, default values, validation)
3. Set up relationships between fields

### Step 3: Use Interface

1. Switch to Interface View
2. Navigate through records using custom UI
3. Edit fields in the interface
4. Changes update CSV in real-time

### Step 4: Share (Optional)

1. Export interface template as JSON
2. Share with team members
3. Anyone with the CSV and template can use the interface

## Comparison to Other Recipes

| Recipe | Purpose |
|--------|---------|
| **Interface** (coming) | Custom-designed UIs matching game/app layouts |
| **Record** | Generic field-and-value record cards |
| **Corkboard** | Visual overview as index cards |
| **Screenplay** | Fixed screenplay format |

Interface Recipe will be the most flexible, allowing you to design exactly the view you need.
