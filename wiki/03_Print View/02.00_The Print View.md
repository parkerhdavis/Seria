# Print System Guide

The Print System is Seria's unique feature that transforms your CSV data into professional page layouts. This guide explains how to use Print previews and edit data directly in the Print view.

## What are Prints?

Prints are **rendered preview formats** that display your CSV data as professional documents. Think of them as templates that map your CSV columns to formatted output.

**Example:** A CSV with columns for "Character", "Dialogue", and "Direction" can be previewed as:

```
CAPTAIN
Battle stations! All hands on deck!

PILOT
(checking sensors)
Three enemy ships incoming!
```

This formatted view is generated live from your CSV data.

## Opening Print Preview

### Toggle Print Preview Panel

**Right/Bottom Panel:**
Click the **Print Preview** button in the toolbar to toggle the Print preview panel.

The panel can be positioned:
- **Right side** - Split view with CSV on left, Print on right
- **Bottom** - CSV on top, Print on bottom

Use the panel position toggle button to switch between layouts.

### Keyboard Shortcuts

- `Ctrl+\` - Toggle right panel
- `Ctrl+/` - Toggle bottom panel

## Bundled Print Templates

Seria comes with two professional Print templates:

### 1. Screenplay Format

Industry-standard screenplay format with proper margins, fonts, and element spacing.

**CSV Columns Required:**
- **Type** - Type of element (Scene, Action, Character, Dialogue, Parenthetical, Transition)
- **Content** - The text content
- **CharacterID** (optional) - Character identifier
- **SceneID** (optional) - Scene identifier
- **Tags** (optional) - Tags for categorization
- **Notes** (optional) - Additional notes

**Element Types:**
- **Scene** - Scene headings (INT./EXT. location - time)
- **Action** - Action description
- **Character** - Character name (auto-centered)
- **Dialogue** - Character dialogue
- **Parenthetical** - Direction for actor (in parentheses)
- **Transition** - Scene transitions (FADE OUT, CUT TO, etc.)

**Example CSV:**
```csv
Type,Content,CharacterID,SceneID,Tags,Notes
Scene,INT. SPACESHIP BRIDGE - DAY,,1,,
Action,The crew rushes to their stations.,,1,,
Character,CAPTAIN,capt,1,,
Dialogue,"Battle stations! All hands on deck!",capt,1,,
Character,PILOT,pilot,1,,
Parenthetical,checking sensors,pilot,1,,
Dialogue,Three enemy ships incoming!,pilot,1,,
```

### 2. Corkboard Format

Visual card-based layout for scene planning, beat sheets, and content overview.

**CSV Columns:**
- **Title** - Card title
- **Subtitle** (optional) - Card subtitle
- **Content** - Card body text (supports multiple columns)

Cards are displayed in a configurable grid layout. See [Corkboard Recipe](wiki/03_Print%20View/02.04_Corkboard%20Recipe.md) for details.

You can also create your own custom Print templates. See [Custom Prints Guide](wiki/04_Customization/03.04_Custom%20Recipes.md) for how to configure them.

## Switching Between Print Templates

1. Open the **Print Preview** panel
2. Click the **Template dropdown** at the top of the panel
3. Select a different template

Your CSV data will instantly re-render in the new format.

**Note:** If your CSV doesn't have the required columns for a template, the Print preview will show an error message or render incorrectly.

## Bidirectional Editing

One of Seria's most powerful features is **bidirectional editing** - you can edit your CSV data directly from the Print preview!

### Editing in Print Preview

1. **Click any text** in the Print preview to start editing
2. **Type your changes**
3. **Click outside** or press `Enter` to save
4. Changes immediately update both the Print view **and** the CSV grid

**What can you edit:**
- Character names
- Dialogue lines
- Directions and notes
- Scene headings
- Action description
- Any text content

**What can't you edit (yet):**
- Element types (e.g., changing "Dialogue" to "Action")
- Column names
- Adding new rows from Print view

### Editing Workflow

**Scenario:** You're reviewing dialogue in Screenplay format and notice a typo.

**Traditional workflow:**
1. Note the typo
2. Switch to CSV view
3. Find the row
4. Edit the cell
5. Switch back to Print view

**Seria workflow:**
1. Click the text in Print view
2. Fix the typo
3. Done!

This makes reviewing and editing formatted documents much faster.

## Print Preview Options

The Print preview panel has several options:

### Zoom Level

Adjust the preview size:
- **Zoom In**: `Ctrl+=`
- **Zoom Out**: `Ctrl+-`
- **Reset Zoom**: `Ctrl+0`

Or use the zoom controls in the Print preview toolbar.

### Page View

Toggle between view modes:
- **Single Page** - Show one page at a time
- **Continuous** - Show all pages in a scrollable view

### Show Page Breaks

Toggle page break indicators on/off to see where pages would end in an exported document.

## Filtering and Prints

The Print preview respects your active CSV filters:

1. Apply filters to your CSV (see [CSV Editing Guide](wiki/02_Cell%20View/01.04_Cell%20Actions.md))
2. The Print preview shows **only the filtered rows**

**Use case:** Filter to show only one character's lines, then preview/edit just their dialogue.

## Exporting Data

Seria provides two export systems:

### Export Templates (`Ctrl+Shift+E`)

Export your CSV data to various formats using built-in or custom templates:
- **JSON** (array, Unity ScriptableObject, Unreal DataTable)
- **Godot Resource** (.tres)
- **Dialogue formats** (Ink, Yarn Spinner)
- **XML** and **YAML**

See [Export Templates](wiki/04_Customization/03.00_Customizing%20Seria.md) for details.

### PDF Export

**Note:** PDF export for Print views is available via the Print toolbar export dialog.

## Print Preview Performance

**Small files (< 1000 rows):** Print preview renders instantly.

**Large files (1000-10,000 rows):** Print preview may take a few seconds to render.

**Very large files (10,000+ rows):** Consider:
- Using filters to show only relevant rows
- Breaking your CSV into smaller files
- Closing the Print preview when editing CSV

4. Edit directly in Print view

## Troubleshooting

### Print preview is blank

**Check:**
- Does your CSV have the required columns for this Print template?
- Are column names spelled correctly? (case-sensitive)
- Do you have at least one data row?

### Text is cut off or overlapping

**Try:**
- Adjusting zoom level
- Resizing the Print preview panel
- Checking for very long text in cells (may need line breaks)

### Changes in Print view aren't saving

**Verify:**
- You pressed `Enter` or clicked outside the edited text
- The CSV grid shows the updated value
- No error message appeared

### Print preview is slow

**For large files:**
- Close the Print preview while editing CSV
- Use filters to reduce visible rows
- Consider splitting very large files
