# Corkboard Recipe

The **Corkboard Recipe** displays your CSV data as a visual grid of index cards, similar to how writers organize scenes on a physical corkboard. This recipe provides a high-level overview of your content, making it easy to see structure, spot patterns, and reorganize at a glance.

---

## What It's For

The Corkboard Recipe is designed for:
- **Scene planning** - Visualize story structure and scene flow
- **Beat sheets** - Organize narrative beats as cards
- **Quest overview** - See all quests or missions at a glance
- **Character tracking** - View character arcs or relationships
- **High-level organization** - Any content that benefits from a visual, card-based layout

Think of it as a digital version of index cards pinned to a corkboard - great for brainstorming, outlining, and restructuring.

---

## How It Presents

The Corkboard Recipe displays each row of your CSV as a card in a grid layout:

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│ Scene 1     │  │ Scene 2     │  │ Scene 3     │
│             │  │             │  │             │
│ Sarah meets │  │ The betrayal│  │ Final       │
│ Alex at...  │  │ revealed... │  │ confronta...│
└─────────────┘  └─────────────┘  └─────────────┘
```

**Card layout:**
- **Title** - Displayed prominently at the top (from a designated CSV column)
- **Subtitle** - Optional secondary information (character, location, etc.)
- **Summary** - Brief description or excerpt
- **Color coding** - Cards can be colored by status, character, or custom tags (coming soon)

---

## Ingredients (CSV Columns)

The Corkboard Recipe expects these CSV columns:

| Column Name | Purpose | Example |
|-------------|---------|---------|
| **Title** | Card heading | "INT. COFFEE SHOP - DAY" |
| **Subtitle** | Secondary info | "Scene 3" or "Chapter 1" |
| **Content** | Card body text | "Sarah confronts Alex about..." |

**Minimal example CSV:**

```csv
Title,Subtitle,Content
The Meeting,Scene 1,Sarah and Alex meet at a coffee shop. Tension is evident.
The Argument,Scene 2,Alex reveals the truth. Sarah is shocked and leaves.
The Decision,Scene 3,Sarah decides to confront the real villain.
```

**Optional columns:**
- **Status** - For color coding (Draft, Final, Cut, etc.)
- **Character** - Main character in scene
- **Location** - Where scene takes place
- **Tags** - Metadata for filtering
- **Notes** - Internal notes (not displayed on card)

## Editing in Corkboard View

When bidirectional editing is enabled, you can click any card element to edit it:

- **Click the title** - Edit the Title column
- **Click the subtitle** - Edit the Subtitle column
- **Click the content** - Edit the Content column

Changes immediately update both the Print view and the Cell view.

See [Bidirectional Editing](wiki/03_Print%20View/02.01_Bidirectional%20Editing.md) for details.

## Tips for Using Corkboard Recipe

### Organizing Your CSV

**Structure your CSV to match your mental model:**
- Each row = one card
- Title = the most important identifier
- Content = the summary or description you want visible at a glance
- Keep content concise - cards work best with brief text

### Workflow Ideas

**Scene planning:**
1. Start with one-line scene descriptions in Corkboard view
2. Drag cards to reorder scenes visually
3. Switch to Cell View to add detailed content
4. Review structure in Corkboard view

**Quest design:**
1. Create cards for each quest
2. Use Subtitle for quest giver or location
3. Content field for brief objective
4. Filter by status or region in Cell View

**Character arcs:**
1. Each card = one character beat
2. Title = character name + beat description
3. Content = emotional state or plot point
4. View all cards to see arc at a glance
