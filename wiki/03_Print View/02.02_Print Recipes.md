# Custom Prints Guide

Learn how to create your own custom Print templates to display CSV data in exactly the format you need.

**Note:** The Custom Print editor is planned for an upcoming release. This guide describes the system and how to manually create Print templates in the meantime.

## What are Custom Prints?

Custom Prints are JSON templates that define:
1. **Which CSV columns** to display
2. **How to style** each element (font, size, indent, spacing, color)
3. **How to format** the output (transformations, page layout)

## Print Template Structure

A Print template is a JSON file with this structure:

```json
{
    "id": "my-custom-print",
    "name": "My Custom Print",
    "description": "Description of what this Print displays",
    "pageSize": {
        "width": 8.5,
        "height": 11,
        "units": "inches"
    },
    "margins": {
        "top": 1,
        "right": 1,
        "bottom": 1,
        "left": 1.5,
        "units": "inches"
    },
    "fieldMappings": {
        "fieldName1": {
            "csvColumn": "ColumnName",
            "style": {
                "font": "Courier New",
                "size": 12,
                "indent": 0,
                "lineSpaceBefore": 0,
                "lineSpaceAfter": 1,
                "color": "#000000",
                "bold": false,
                "italic": false,
                "uppercase": false
            },
            "transform": null
        }
    }
}
```

## Creating a Custom Print (Manual Method)

Until the visual editor is released, you can create custom Prints by writing JSON files.

### Step 1: Plan Your Print

**Identify:**
1. What CSV columns you want to display
2. How each column should be styled
3. What order elements should appear

**Example:** Quest data print for a game

**CSV columns:**
- QuestName
- QuestGiver
- Description
- Rewards

**Desired output:**
```
QUEST: Dragon Slayer

Given by: Elder Mage

Description: Travel to the mountain and defeat the dragon
that has been terrorizing the village.

Rewards: 500 gold, Dragon Scale Armor
```

### Step 2: Write the JSON Template

Create a file `quest-print.json`:

```json
{
    "id": "quest-print",
    "name": "Quest Format",
    "description": "Displays game quests in readable format",
    "pageSize": {
        "width": 8.5,
        "height": 11,
        "units": "inches"
    },
    "margins": {
        "top": 1,
        "right": 1,
        "bottom": 1,
        "left": 1,
        "units": "inches"
    },
    "fieldMappings": {
        "questName": {
            "csvColumn": "QuestName",
            "style": {
                "font": "Arial",
                "size": 14,
                "indent": 0,
                "lineSpaceBefore": 2,
                "lineSpaceAfter": 1,
                "color": "#000000",
                "bold": true,
                "uppercase": true
            },
            "prefix": "QUEST: "
        },
        "questGiver": {
            "csvColumn": "QuestGiver",
            "style": {
                "font": "Arial",
                "size": 11,
                "indent": 0,
                "lineSpaceBefore": 0,
                "lineSpaceAfter": 1,
                "color": "#666666",
                "italic": true
            },
            "prefix": "Given by: "
        },
        "description": {
            "csvColumn": "Description",
            "style": {
                "font": "Arial",
                "size": 12,
                "indent": 0,
                "lineSpaceBefore": 1,
                "lineSpaceAfter": 1,
                "color": "#000000"
            },
            "prefix": "Description: "
        },
        "rewards": {
            "csvColumn": "Rewards",
            "style": {
                "font": "Arial",
                "size": 12,
                "indent": 0,
                "lineSpaceBefore": 1,
                "lineSpaceAfter": 2,
                "color": "#008000",
                "bold": true
            },
            "prefix": "Rewards: "
        }
    }
}
```

### Step 3: Install the Custom Print

**Linux:**
```bash
mkdir -p ~/.local/share/Seria/prints
cp quest-print.json ~/.local/share/Seria/prints/
```

**Windows:**
```powershell
New-Item -Path "$env:LOCALAPPDATA\seria\prints" -ItemType Directory -Force
Copy-Item quest-print.json "$env:LOCALAPPDATA\seria\prints\"
```

### Step 4: Use the Custom Print

1. Restart Seria (if it was running)
2. Open your CSV file
3. Open Print Preview
4. Select your custom Print from the template dropdown
5. Your CSV data now displays in your custom format!

## Template Options Reference

### Page Size

```json
"pageSize": {
    "width": 8.5,      // Page width
    "height": 11,      // Page height
    "units": "inches"  // "inches" or "cm"
}
```

**Common sizes:**
- US Letter: 8.5 x 11 inches
- A4: 21 x 29.7 cm
- Legal: 8.5 x 14 inches

### Margins

```json
"margins": {
    "top": 1,
    "right": 1,
    "bottom": 1,
    "left": 1.5,
    "units": "inches"
}
```

### Field Mapping

Each field mapping defines how one CSV column is displayed:

```json
"fieldName": {
    "csvColumn": "CSVColumnName",  // Required: CSV column name
    "style": { ... },                // Required: Styling options
    "prefix": "Label: ",             // Optional: Text before value
    "suffix": "",                    // Optional: Text after value
    "transform": "uppercase"         // Optional: Transform function
}
```

### Style Options

```json
"style": {
    "font": "Arial",              // Font family
    "size": 12,                   // Font size in points
    "indent": 0,                  // Left indent (inches/cm)
    "lineSpaceBefore": 1,         // Lines before element
    "lineSpaceAfter": 1,          // Lines after element
    "color": "#000000",           // Text color (hex)
    "bold": false,                // Bold text
    "italic": false,              // Italic text
    "uppercase": false,           // Convert to uppercase
    "alignment": "left"           // "left", "center", "right"
}
```

### Transforms

Optional text transformations:

- `"uppercase"` - Convert to UPPERCASE
- `"lowercase"` - Convert to lowercase
- `"capitalize"` - Capitalize First Letter Of Each Word
- `"trim"` - Remove leading/trailing whitespace
- Custom JavaScript function (advanced)

## Visual Print Editor (Coming Soon)

A visual Print editor is in development that will let you:

- **Drag and drop** CSV columns to Print fields
- **Live preview** as you configure styles
- **Visual style editor** for fonts, colors, spacing
- **Sample data preview** to test your Print
- **Save and share** custom Prints easily

Until then, manually creating JSON files is the way to create custom Prints.

## Sharing Custom Prints

Want to share your custom Print with others?

1. Find your Print JSON file in the prints directory
2. Share the file with collaborators
3. They install it to their prints directory
4. Everyone can use the same Print format!

**Prints directory locations:**
- Linux: `~/.local/share/Seria/prints/`
- Windows: `%LOCALAPPDATA%\seria\prints\`

## Troubleshooting

### Custom Print doesn't appear in dropdown

**Check:**
- JSON file is in the correct prints directory
- JSON is valid (use a JSON validator)
- Seria was restarted after adding the file

### Print displays incorrectly

**Verify:**
- `csvColumn` names match your CSV columns exactly (case-sensitive)
- All required fields are present in JSON
- Style values are valid (e.g., color is valid hex code)

### Text is cut off

**Try:**
- Reducing font size
- Increasing margins
- Adjusting line spacing
