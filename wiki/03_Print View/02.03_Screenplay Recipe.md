# Screenplay Recipe

The **Screenplay Recipe** formats your CSV data into professional screenplay format, following industry-standard layout and spacing conventions. This recipe is ideal for game writers who need to present dialogue and action in a familiar, readable screenplay style.

---

## What It's For

The Screenplay Recipe is designed for:
- **Game dialogue** that needs to be reviewed by voice actors or directors
- **Cutscene scripts** formatted for cinematics teams
- **Narrative documentation** presented in a professional screenplay format
- **Collaboration** with writers familiar with screenplay conventions

Think of it as transforming your CSV data into something that looks like a film or TV script.

---

## How It Presents

The Screenplay Recipe displays your CSV data using standard screenplay formatting:

### Scene Headings

```
INT. SPACESHIP BRIDGE - DAY
```

- All caps
- Flush left
- Extra spacing above and below

### Action Lines

```
Sarah rushes to the control panel and frantically presses buttons.
The lights flicker.
```

- Regular case
- Flush left
- Single-spaced
- Blank line between paragraphs

### Character Names

```
                    SARAH
```

- All caps
- Centered (or slightly left of center)
- Extra spacing above

### Dialogue

```
                    SARAH
              We need to get out of here
              before the system overloads.
```

- Regular case
- Indented (centered column, narrower than action)
- Single-spaced

### Parentheticals

```
                    SARAH
                  (panicked)
              We need to evacuate now!
```

- Lowercase (except first letter)
- Further indented
- Placed between character name and dialogue

### Transitions

```
                                        CUT TO:
```

- All caps
- Flush right
- Extra spacing

## Ingredients (CSV Columns)

The Screenplay Recipe expects these CSV columns:

| Column Name | Purpose | Format |
|-------------|---------|--------|
| **Type** | Element type | `Scene`, `Action`, `Character`, `Dialogue`, `Parenthetical`, `Transition` |
| **Content** | The text content | Free-form text |

**Minimal example CSV:**

```csv
Type,Content
Scene,INT. SPACESHIP - DAY
Action,Sarah enters the bridge.
Character,SARAH
Dialogue,Hello computer. Status report.
Action,The computer beeps.
Character,COMPUTER
Parenthetical,robotic voice
Dialogue,All systems nominal.
Transition,CUT TO:
```

**Optional columns:**
- **CharacterID** - For filtering/grouping by character
- **SceneID** - For organizing by scene
- **Tags** - For metadata (cut content, temp dialogue, etc.)
- **Notes** - Internal notes (not displayed in Print)

## Example Output

Given this CSV data:

| Type | Content |
|------|---------|
| Scene | INT. COFFEE SHOP - DAY |
| Action | ALEX sits alone at a corner table, staring at a laptop. |
| Character | BARISTA |
| Parenthetical | cheerfully |
| Dialogue | What can I get you? |
| Character | ALEX |
| Parenthetical | not looking up |
| Dialogue | Just coffee. Black. |

The Screenplay Recipe displays:

```
INT. COFFEE SHOP - DAY

ALEX sits alone at a corner table, staring at a laptop.

                    BARISTA
                  (cheerfully)
              What can I get you?

                    ALEX
                (not looking up)
              Just coffee. Black.
```

## Editing in Screenplay View

When bidirectional editing is enabled, you can click any element in the Screenplay view to edit it:

- **Click a scene heading** - Edit the scene description
- **Click an action line** - Edit the action text
- **Click a character name** - Edit the character name
- **Click dialogue** - Edit the dialogue content
- **Click a parenthetical** - Edit the parenthetical

Changes immediately update both the Print view and the Cell view.

## Tips for Using Screenplay Recipe

### Organizing Your CSV

**Option 1: Chronological order**
- Enter scenes, actions, and dialogue in the order they appear
- Easy to read top-to-bottom in Cell View

**Option 2: Character-grouped**
- Group all lines by character using the CharacterID column
- Use Cell View filtering to work on one character at a time
- Switch to Print View to see full scenes

### Writing Workflow

1. **Draft in Print View** - Write naturally in screenplay format
2. **Organize in Cell View** - Add metadata, tags, IDs
3. **Review in Print View** - Check pacing, flow, readability
4. **Filter in Cell View** - Find specific character lines or scenes
5. **Polish in Print View** - Final dialogue tweaks

### Screenplay Conventions

The Screenplay Recipe follows these standard conventions:
- Scene headings use `INT.` or `EXT.` + location + time of day
- Character names are UPPERCASE when introduced in action
- Dialogue avoids "on the nose" exposition (this is a writing tip, not a technical requirement)
- Transitions (CUT TO, FADE OUT) used sparingly
