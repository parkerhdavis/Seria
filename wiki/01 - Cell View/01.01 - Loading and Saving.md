# Your First CSV

This guide walks you through opening, editing, and saving your first CSV or TSV file in Seria.

**Supported formats:** Seria currently supports CSV (comma-separated) and TSV (tab-separated) files. JSON support is coming soon.

## Opening a CSV or TSV File

There are several ways to open a CSV or TSV file:

### Method 1: Open Button

1. Click the **Open** button in the toolbar
2. Navigate to your CSV or TSV file in the file dialog
3. Click **Open**

### Method 2: Keyboard Shortcut

Press `Ctrl+O` (Windows/Linux) or `Cmd+O` (macOS) to open the file dialog.

### Method 3: Drag and Drop

Drag a CSV or TSV file from your file manager and drop it onto the Seria window.

### Method 4: File Tree Sidebar

1. Press `Ctrl+.` to toggle the file tree sidebar
2. Navigate to your CSV or TSV file
3. Click the file to open it

## Understanding the Interface

Once your file is open, you'll see:

### CSV Grid

The main editing area displays your CSV data in a spreadsheet-like grid:

- **Headers** - Top row shows column names
- **Cells** - Data arranged in rows and columns
- **Selection** - Blue border shows selected cell
- **Row Numbers** - Left side shows row numbers (1, 2, 3...)

### File Info Bar

At the top, you'll see information about your file:

- **File name** - Name of the open CSV file
- **Row count** - Number of data rows (excluding header)
- **Column count** - Number of columns
- **Status** - "Unsaved" indicator appears when you have changes

### Column Summaries

At the bottom of the grid, each column shows summary statistics:

- **Count** - Number of non-empty values (default)
- Click the dropdown to change: Unique, Mode, Average, Min, Max, Sum

## Basic Editing

### Selecting a Cell

**Click once** on any cell to select it. The selected cell will have a blue border.

**Keyboard navigation:**
- `↑` `↓` `←` `→` - Move selection with arrow keys
- `Tab` - Move to next column
- `Shift+Tab` - Move to previous column
- `Enter` - Move to next row (same column)
- `Shift+Enter` - Move to previous row (same column)

### Editing a Cell

There are three ways to start editing a cell:

1. **Double-click** the cell
2. **Select the cell** and press `F2`
3. **Select the cell** and press `Enter`

Once editing:
- **Type** your changes
- **Enter** - Save and move to next row
- **Tab** - Save and move to next column
- **Escape** - Cancel without saving

**Pro tip:** You can click outside the cell while editing to automatically save your changes.

### Adding Rows

**Add row at the end:**
- Click the **Add Row** button in the toolbar
- Or press `Ctrl+Enter`

**Insert row at specific position:**
- Right-click any cell
- Select **Insert Row Above** or **Insert Row Below**

### Copy and Paste

**Copy:**
1. Select one or more cells (click and drag)
2. Press `Ctrl+C`

**Paste:**
1. Select destination cell(s)
2. Press `Ctrl+V`

**Smart paste modes:**
- Paste single cell → Pastes value
- Paste range → Pastes entire range
- Paste single cell into multiple selected cells → Fills all selected cells
- Paste row into column → Tiles the data

### Undo and Redo

Made a mistake? No problem!

- **Undo**: `Ctrl+Z` (or toolbar button)
- **Redo**: `Ctrl+Shift+Z` or `Ctrl+Y` (or toolbar button)

Seria tracks all your changes, so you can undo back to when you opened the file.

## Saving Your Work

### Save to Current File

Click the **Save** button or press `Ctrl+S` to save changes to the current file.

The "Unsaved" indicator will disappear when your changes are saved.

### Save As New File

Want to save a copy with a different name?

1. Click the menu (three dots) in the toolbar
2. Select **Save As**
3. Choose location and filename
4. Click **Save**

### Auto-Save

Seria **automatically saves** your changes after you finish editing cells. By default, autosave is enabled with a 30-second timer.

**How it works:**
- After you confirm a cell edit (press Enter, Tab, or click away), the autosave timer starts
- If you make another edit before the timer expires, it resets
- When the timer reaches zero, your file is automatically saved
- The "Unsaved" indicator will clear when autosave completes

**Configure autosave:**
1. Press `Ctrl+,` to open Settings
2. Go to the **File Saving** section
3. Toggle autosave on/off or adjust the interval (5 seconds to 5 minutes)

**Best practice:** While autosave is enabled by default, you can still manually save anytime with `Ctrl+S` for important checkpoints or before closing the app.

## Closing a File

**Close current file:**
1. Click the menu (three dots)
2. Select **Close File**

If you have unsaved changes, Seria will ask if you want to save before closing.

## Example Workflow

Let's walk through a complete editing session:

### 1. Open a file
```
Press Ctrl+O → Select "game_items.csv" → Click Open
```

### 2. Edit a cell
```
Double-click "Sword" in the Name column
Change it to "Long Sword"
Press Enter to save and move to next row
```

### 3. Add a new item
```
Press Ctrl+Enter to add a new row
Fill in the cells: "Shield", "Armor", "50", "Provides protection"
```

### 4. Copy an existing item
```
Select the row for "Potion" (click row number)
Press Ctrl+C to copy
Click the first cell of an empty row
Press Ctrl+V to paste
Edit the name to "Mega Potion"
Edit the other values as needed
```

### 5. Save your changes
```
Press Ctrl+S to save
The "Unsaved" indicator disappears
```

### 6. Close the file
```
Click menu → Close File
```

**Congratulations!** You've successfully edited your first CSV file in Seria. 🎉

## Common Beginner Questions

### Q: How do I delete a row?

**A:** Row deletion is coming in a future update. For now, select all cells in the row and delete their contents, or remove the row in a text editor.

### Q: Can I edit column names?

**A:** Yes! Column headers are editable just like regular cells. Double-click the header to edit it.

### Q: What if I accidentally close a file without saving?

**A:** If you've been editing cells, autosave likely saved your recent changes (by default, it saves 30 seconds after your last edit). However, if you have very recent unsaved changes (within the autosave timer window), those will be lost. You can also manually save anytime with `Ctrl+S` to ensure all changes are saved immediately.

### Q: Can I work with multiple CSV files at once?

**A:** Currently, Seria supports one file at a time. Close the current file before opening another.

### Q: The file looks wrong - cells are in the wrong columns!

**A:** This can happen if your file uses an unsupported delimiter. Seria currently supports:
- CSV files (comma-separated: `,`)
- TSV files (tab-separated)

If your file uses semicolons (`;`) or pipes (`|`), you'll need to convert it. Check the [Troubleshooting Guide](wiki/ORGANIZE%20THESE%20INTO%20MY%20STRUCTURE/21-Troubleshooting.md) for help.
