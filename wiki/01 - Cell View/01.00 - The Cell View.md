# The Cell View

The **Cell View** is Seria's primary editing interface - a spreadsheet-like grid where you work directly with your CSV/TSV data. It's designed to feel familiar if you've used Excel or Google Sheets, but streamlined for content editing rather than calculations.

---

## Layout Overview

The Cell View consists of four main areas:

### 1. Toolbar (Top)

The toolbar provides quick access to common operations:
- **File operations** - Open, Save, Save As
- **Undo/Redo** - Track and reverse changes
- **Add Row/Column** - Insert new data
- **Filter/Sort** - Organize your view
- **Settings** - Configure preferences

See [The Toolbar](01.02%20-%20The%20Toolbar.md) for detailed documentation.

---

### 2. Data Grid (Center)

The main editing area displays your CSV data as a table:

**Column Headers:**
- Display column names from the first row of your CSV
- Click to sort by that column
- Right-click for column operations (insert, delete, filter)
- Drag headers to reorder columns

**Row Numbers:**
- Display along the left edge
- Click to select entire row
- Drag to reorder rows
- Right-click for row operations (insert, delete)

**Cells:**
- Display your data values
- Click to select, F2 or Enter to edit
- Support text, numbers, and long-form content
- Color-coding based on user-defined rules (coming soon)

---

### 3. Left Sidebar (Optional)

Toggle with `Ctrl+.` to show/hide the file tree:
- Browse local files and folders
- Quick-open CSV/TSV files
- See recently opened files (coming soon)

---

### 4. Right or Bottom Panel (Optional)

Toggle with `Ctrl+\` (right) or `Ctrl+/` (bottom) to show Print preview:
- View your CSV data in formatted layouts
- Edit directly in the Print view (bidirectional editing)
- Switch between different Print templates

See [The Print View](../02%20-%20Print%20View/02.00%20-%20The%20Print%20View.md) for details.

## Navigation

### Mouse Navigation

- **Click a cell** - Select it
- **Double-click a cell** - Start editing
- **Click and drag** - Select multiple cells
- **Scroll** - Pan through large datasets

### Keyboard Navigation

- **Arrow keys** - Move selection up/down/left/right
- **Tab** - Move to next column
- **Shift+Tab** - Move to previous column
- **Enter** - Move to next row
- **Home** - Jump to first column in row
- **End** - Jump to last column in row
- **Ctrl+Home** - Jump to first cell (top-left)
- **Ctrl+End** - Jump to last cell (bottom-right)

See [Keyboard Shortcuts](../03%20-%20Customization/03.02%20-%20Keyboard%20Shortcuts.md) for the complete list.

## Editing Workflow

Seria uses a **two-step editing model** for precision and safety:

1. **Select** - Click a cell to select it (blue border)
2. **Edit** - Press F2 or Enter to start editing

**While editing:**
- Type your changes
- Press **Enter** to save and move down
- Press **Tab** to save and move right
- Press **Escape** to cancel

This prevents accidental edits when navigating and gives you clear visual feedback about what you're doing.

See [Cell Actions](01.04%20-%20Cell%20Actions.md) for detailed editing features.

## Grid Features

### Filtering

Filter rows based on column values:
1. Click the filter icon in a column header
2. Choose filter criteria (contains, equals, starts with, etc.)
3. Type your filter value
4. Rows that don't match are hidden (not deleted)

Clear filters with `Ctrl+Shift+F` or click "Clear All Filters" in the toolbar.

### Sorting

Sort rows by column values:
- **Click column header once** - Sort ascending
- **Click again** - Sort descending
- **Shift+Click** - Add secondary sort

Sorting is non-destructive - your original row order is preserved in the file until you save.

### Selection

Select cells for bulk operations:
- **Single cell** - Click
- **Row** - Click row number
- **Column** - Click column header
- **Range** - Click and drag
- **All** - Press `Ctrl+A`

Selected cells can be copied, pasted, or cleared as a group.

## Working with Large Files

For CSV files with hundreds or thousands of rows, Seria optimizes performance:

- **Virtualization** - Only visible rows are rendered (fast scrolling)
- **Lazy loading** - Data loads progressively
- **Efficient updates** - Changes apply instantly without re-rendering the entire grid

**Current limitations:**
- Files with 1,000+ rows may have some performance issues (being optimized)
- Very wide files (100+ columns) may require horizontal scrolling

See [Current Limitations](../04%20-%20FAQ%20and%20Support/04.01%20-%20Current%20Limitations.md) for known issues.

## Customization

The Cell View respects your preferences:

- **Theme** - Light or dark mode (`Ctrl+T` to toggle)
- **Font size** - Zoom in/out with `Ctrl+=/Ctrl+-`
- **Column widths** - Drag column borders to resize
- **Row heights** - Auto-adjust based on content (coming soon)

Settings are saved per-file, so different CSVs can have different configurations.

See [File and Global Configs](../03%20-%20Customization/03.03%20-%20File%20and%20Global%20Configs.md) for how settings are stored.

## Tips for Efficient Workflow

**Quick data entry:**
1. Select starting cell
2. Press F2 to edit
3. Type value
4. Press Tab (move right) or Enter (move down)
5. Repeat

**Fast filtering:**
1. Click filter icon in header
2. Type filter text
3. Press Enter

**Bulk editing:**
1. Type value in first cell
2. Copy with `Ctrl+C`
3. Select range of cells
4. Paste with `Ctrl+V`

**Undo mistakes:**
- `Ctrl+Z` to undo
- `Ctrl+Shift+Z` or `Ctrl+Y` to redo
