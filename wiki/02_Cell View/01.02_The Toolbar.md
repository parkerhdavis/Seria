# The Toolbar

The toolbar sits at the top of the Cell View and provides quick access to common file operations, editing commands, and view controls. This guide details each button and its function.

---

## Toolbar Layout

The toolbar is organized into logical groups from left to right:

1. **File Operations** - Open, Save, Close
2. **Edit Operations** - Undo, Redo
3. **Data Operations** - Add Row, Add Column
4. **View Controls** - Filter, Sort, Find
5. **Panel Toggles** - Sidebar, Print Preview
6. **Settings** - Preferences and configuration

---

## File Operations

### Open

**Icon:** Folder icon

**Shortcut:** `Ctrl+O`

**Function:** Opens a file dialog to select and load a CSV or TSV file.

**Notes:**
- Prompts to save if current file has unsaved changes
- Remembers last opened directory
- Supports drag-and-drop as alternative

---

### Save

**Icon:** Floppy disk icon

**Shortcut:** `Ctrl+S`

**Function:** Saves changes to the current file.

**Behavior:**
- If file was opened from disk, overwrites that file
- If new file (never saved), opens Save As dialog
- Auto-save also runs periodically (configurable in Settings)

**Visual feedback:**
- Toolbar shows "Saved" confirmation briefly
- Title bar asterisk (*) disappears when file is saved

---

### Save As

**Icon:** Floppy disk with arrow

**Shortcut:** `Ctrl+Shift+S`

**Function:** Saves the current data to a new file location.

**Use cases:**
- Creating a copy with a different name
- Saving to a different directory
- Converting between CSV and TSV (change file extension)

---

### Close File

**Icon:** X icon

**Shortcut:** `Ctrl+W`

**Function:** Closes the current file.

**Notes:**
- Prompts to save if there are unsaved changes
- Closes all associated views (Print preview, etc.)
- Returns to empty state (file tree visible if enabled)

---

## Edit Operations

### Undo

**Icon:** Curved arrow pointing left

**Shortcut:** `Ctrl+Z`

**Function:** Reverts the last change made to the CSV data.

**What can be undone:**
- Cell edits
- Row/column additions
- Row/column deletions
- Bulk paste operations
- Row/column reordering

**Limitations:**
- Undo history clears when file is closed
- Cannot undo across file open/close
- Some settings changes aren't tracked in undo history

---

### Redo

**Icon:** Curved arrow pointing right

**Shortcut:** `Ctrl+Shift+Z` or `Ctrl+Y`

**Function:** Re-applies a change that was undone.

**Notes:**
- Only available after using Undo
- Redo history clears if you make a new edit after undoing

---

## Data Operations

### Add Row

**Icon:** Plus icon with horizontal line

**Shortcut:** `Ctrl+Enter`

**Function:** Adds a new empty row at the end of the CSV.

**Alternative:**
- Right-click a row number → "Insert Row Above"
- Use `Ctrl+Shift+Enter` to insert above current row

---

### Insert Column

**Icon:** Plus icon with vertical line

**Shortcut:** `Ctrl+]`

**Function:** Adds a new empty column.

**Placement:**
- If a cell is selected, inserts to the right of that column
- If no selection, adds at the end

**Alternative:**
- Right-click a column header → "Insert Column Left" or "Insert Column Right"

---

## View Controls

### Find

**Icon:** Magnifying glass

**Shortcut:** `Ctrl+F`

**Function:** Opens the Find dialog to search for text in the CSV.

**Features:**
- Search all columns or specific column
- Case-sensitive option
- Navigate to next/previous match
- Highlights all matches in the grid

**Related:** `Ctrl+R` or `Ctrl+H` for Find and Replace

---

### Filter

**Icon:** Funnel icon

**Shortcut:** Click column header filter icon

**Function:** Opens filter controls for organizing visible rows.

**How it works:**
1. Click funnel icon in any column header
2. Choose filter type (contains, equals, starts with, etc.)
3. Enter filter value
4. Rows not matching are hidden (not deleted)

**Clear filters:**
- `Ctrl+Shift+F` - Clear all filters
- Click "Clear Filters" button in toolbar
- Click filter icon again and remove criteria

---

### Sort

**Icon:** A-Z icon with arrow

**Shortcut:** Click column header

**Function:** Sorts rows by column values.

**Behavior:**
- First click: Sort ascending (A→Z, 0→9)
- Second click: Sort descending (Z→A, 9→0)
- `Shift+Click`: Add secondary sort

**Notes:**
- Sorting is visual only until file is saved
- Original order preserved until save
- Multi-column sorting supported

---

## Panel Toggles

### Toggle Left Sidebar

**Icon:** Sidebar icon (left)

**Shortcut:** `Ctrl+.`

**Function:** Shows/hides the file tree sidebar.

**Use cases:**
- Browse and open files
- Quick navigation between CSVs
- Hide to maximize grid space

---

### Toggle Print Preview (Right)

**Icon:** Panel icon (right)

**Shortcut:** `Ctrl+\`

**Function:** Shows/hides the Print preview panel on the right side.

**Features:**
- View CSV data in formatted layouts
- Edit directly in Print view (bidirectional editing)
- Dropdown to switch between Print templates

See [Print View](wiki/03_Print%20View/02.00_The%20Print%20View.md) for details.

---

### Toggle Print Preview (Bottom)

**Icon:** Panel icon (bottom)

**Shortcut:** `Ctrl+/`

**Function:** Shows/hides the Print preview panel at the bottom.

**Notes:**
- Alternative layout for Print preview
- Useful for wide CSVs where horizontal space is limited
- Same functionality as right panel, just different placement

---

## Settings

### Open Settings

**Icon:** Gear icon

**Shortcut:** `Ctrl+,`

**Function:** Opens the Settings dialog.

**Settings categories:**
- **Appearance** - Theme, font size, colors
- **File Saving** - Auto-save interval, backup options
- **Editor** - Default behaviors, keyboard shortcuts
- **Print Templates** - Manage custom Print templates
- **Advanced** - Developer options, experimental features

See [Basic App Settings](wiki/04_Customization/03.01_Basic%20App%20Settings.md) for details.

---

### Toggle Theme

**Icon:** Sun/Moon icon

**Shortcut:** `Ctrl+T`

**Function:** Switches between light and dark mode.

**Notes:**
- Changes apply immediately
- Preference saved per-user (not per-file)
- System theme detection (coming soon)

---

### Help

**Icon:** Question mark icon

**Shortcut:** `F1`

**Function:** Opens the documentation (this wiki) or shows quick help overlay.

**Options:**
- View full documentation
- See keyboard shortcuts reference
- Check for updates
- About Seria

---

## Status Bar (Bottom)

While not part of the toolbar, the status bar at the bottom of the window provides useful context:

**Left side:**
- Current file path
- File modified indicator (*)

**Center:**
- Current cell position (e.g., "Row 5, Column 3")
- Selection info (e.g., "4 cells selected")

**Right side:**
- Row count (e.g., "125 rows")
- Column count (e.g., "8 columns")
- Filter status (e.g., "Filtered: 50 of 125 rows")

---

## Context Menus

Right-clicking in different areas provides context-specific options:

**Right-click a cell:**
- Copy
- Paste
- Clear cell
- Insert row above/below
- Filter by this value

**Right-click a row number:**
- Insert row above/below
- Delete row (coming soon)
- Copy row
- Select entire row

**Right-click a column header:**
- Insert column left/right
- Delete column (coming soon)
- Sort ascending/descending
- Open filter
- Resize column
