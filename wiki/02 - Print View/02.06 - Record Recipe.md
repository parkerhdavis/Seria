# Record Recipe

The **Record Recipe** displays individual CSV rows as detailed, card-style records with labeled fields. This recipe is ideal for viewing structured data like character profiles, item databases, or quest details where each row represents a complete entity with multiple attributes.

---

## What It's For

The Record Recipe is designed for:
- **Character profiles** - View character details (name, bio, stats, relationships)
- **Item databases** - Display item records (name, description, stats, lore)
- **Quest details** - Show quest information (title, giver, objectives, rewards)
- **Location records** - Present location data (name, description, NPCs, items)
- **Any structured records** - Anything where rows are complete entities with named attributes

Think of it as viewing your CSV data in a database record card format, rather than a spreadsheet grid.

---

## How It Presents

The Record Recipe displays each row as a formatted record with field labels:

```
┌─────────────────────────────────────┐
│ CHARACTER RECORD                    │
├─────────────────────────────────────┤
│ Name: Sarah Chen                    │
│ Role: Engineer                      │
│ Age: 32                             │
│                                     │
│ Background:                         │
│ Former military engineer who joined │
│ the civilian space program after    │
│ the war. Brilliant but haunted by   │
│ past decisions.                     │
│                                     │
│ Skills: Engineering, Piloting       │
│ Relationships: Rival of Alex        │
└─────────────────────────────────────┘
```

**Record layout:**
- **Field labels** - CSV column names displayed as labels
- **Field values** - Cell contents displayed beneath labels
- **Sections** - Grouping related fields together
- **Formatting** - Different styles for different field types (title, description, stats)

---

## Ingredients (CSV Columns)

The Record Recipe uses **all columns** in your CSV, displaying each as a labeled field.

**Example CSV structure:**

```csv
Name,Class,Level,HP,MP,Description
Warrior,Fighter,10,120,20,A powerful melee combatant
Mage,Wizard,8,60,150,Master of arcane arts
Rogue,Thief,12,80,40,Sneaky and deadly
```

**Each column becomes a field in the record:**
- `Name` → Displayed as title/heading
- `Class`, `Level`, `HP`, `MP` → Displayed as labeled stats
- `Description` → Displayed as multi-line text block

## Navigation Between Records

**In Record View:**
- **Next button** or `→` key - View next record (next CSV row)
- **Previous button** or `←` key - View previous record
- **Jump to record** - Enter row number to view specific record

**In Cell View:**
- Select a row, then switch to Record View to see that record

## Editing in Record View

When bidirectional editing is enabled, you can click any field value to edit it:

- **Click a field value** - Edit that cell's content
- Changes update both Record View and Cell View instantly
- Long text fields expand for comfortable editing

## Tips for Using Record Recipe

### Organizing Your CSV

**Structure your CSV for record viewing:**
- **First column** = Primary identifier (Name, ID, Title)
- **Important fields first** = Role, Type, Status
- **Description fields** = Long-form text (bio, flavor text, notes)
- **Technical fields last** = IDs, tags, internal metadata

This ordering makes records easier to scan in Record View.

### Workflow Ideas

**Character creation:**
1. Add new character row in Cell View
2. Fill in name and basic stats
3. Switch to Record View
4. Write long-form background/bio in formatted layout
5. Navigate between characters using arrow keys

**Item database:**
1. Enter items in Cell View (names, stats, costs)
2. Switch to Record View
3. Write flavor text and lore descriptions
4. Review each item record sequentially
5. Edit stats in Cell View, descriptions in Record View

**Quest management:**
1. Create quest rows with basic info
2. View in Record View to see full quest details
3. Edit objectives and rewards in formatted view
4. Filter quests by status in Cell View, then review filtered quests in Record View

## Comparison to Other Recipes

| Recipe | Best For |
|--------|----------|
| **Record** | Viewing/editing individual detailed records |
| **Corkboard** | Overview of all records as cards |
| **Cell View** | Bulk editing, filtering, sorting multiple records |
| **Screenplay** | Sequential narrative content |

**When to use Record vs. Corkboard:**
- **Record** - Deep dive into one record at a time
- **Corkboard** - See all records at once for comparison/organization
