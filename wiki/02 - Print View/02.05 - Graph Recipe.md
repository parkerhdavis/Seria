# Graph Recipe

The **Graph Recipe** visualizes your CSV data as charts and graphs, making it easy to spot patterns, trends, and relationships in your content. This recipe is useful for game designers who need to visualize numerical data, track balance metrics, or present data-driven insights.

---

## What It's For

The Graph Recipe is designed for:
- **Game balance visualization** - See stat distributions, power curves, cost/benefit ratios
- **Narrative structure** - Visualize pacing, tension curves, character presence
- **Content tracking** - Charts showing quest distribution, dialogue counts, scene lengths
- **Data analysis** - Any structured data that benefits from visual representation

Think of it as a lightweight data visualization tool built into your CSV editor.

## Ingredients (CSV Columns)

The Graph Recipe expects columns with **numerical or categorical data**:

**For bar/pie charts:**
| Column Name | Purpose |
|-------------|---------|
| **Category** | X-axis labels |
| **Value** | Numerical values to plot |

**For line/scatter charts:**
| Column Name | Purpose |
|-------------|---------|
| **X** | Horizontal axis values |
| **Y** | Vertical axis values |
| **Series** (optional) | Multiple lines/series |

**Minimal example CSV:**

```csv
Character,LineCount
Sarah,145
Alex,98
Jordan,67
Computer,23
```

## Example Output

Given this CSV data (item stats):

| ItemName | Cost | Power | Rarity |
|----------|------|-------|--------|
| Sword | 100 | 10 | Common |

## Configuring Graphs

**In the Print View controls:**
1. Select chart type (bar, line, pie, scatter)
2. Choose X and Y columns
3. Optional: Add series column for multi-line charts
4. Optional: Filter data before graphing

**Settings saved:**
- Graph configurations are saved per-file
- Switch between different graph views with dropdown

---

## Editing Data from Graph View

Unlike other recipes, the Graph Recipe is primarily **read-only** for viewing visualizations.

**To edit the underlying data:**
1. Click a data point in the graph (coming soon) - jumps to that row in Cell View
2. Edit values in Cell View
3. Graph updates automatically to reflect changes

## Tips for Using Graph Recipe

### Preparing Your Data

**For best results:**
- Ensure numerical columns contain valid numbers (no text like "N/A")
- Use consistent categories (avoid typos like "common" vs. "Common")
- Remove empty rows that might skew charts
- Filter data before graphing if you only want to visualize a subset

### Common Use Cases

**Game balance:**
- Plot item cost vs. power to find outliers
- Graph skill costs by level to check progression curves
- Visualize stat distributions to ensure variety

**Narrative analysis:**
- Chart dialogue counts by character
- Plot scene lengths to check pacing
- Visualize story beats on a timeline

**Content tracking:**
- Pie chart of quest types (main, side, hidden)
- Bar chart of dialogue lines per act
- Line chart of tension/emotion over time

## Limitations

**Current limitations:**
- Limited chart types (bar, line, pie, scatter)
- No advanced features like trendlines, error bars, or annotations
- Cannot edit data directly in graph view
- No export to image (PDF export coming soon)

**For advanced visualization:**
- Export CSV to Excel, Google Sheets, or dedicated charting tools
- Use Seria for quick, at-a-glance visualization during editing
