# Getting Started with Seria

This guide will help you install Seria and get started with your first CSV file.

## Installation

### Download Seria

**Release builds** (recommended for most users):
- Stable, tested versions with complete features
- **Current release:** [v0.0.1](https://gitlab.com/parkerhdavis/Seria/-/releases/0.0.1)
- Download from [GitLab Releases](https://gitlab.com/parkerhdavis/Seria/-/releases)

**Dev builds** (for testing and early access):
- Unstable builds between releases with latest changes
- May contain bugs or incomplete features
- Download from [GitLab Package Registry](https://gitlab.com/parkerhdavis/Seria/-/packages)
- **Current dev build:** [Latest packages](https://gitlab.com/parkerhdavis/Seria/-/packages/49127029) (note: this link updates with each dev build)

### Linux Installation

Seria is available in three formats for Linux:

#### AppImage (Recommended for most users)

The AppImage is a universal binary that works on most Linux distributions without installation.

**Steps:**
1. Download the AppImage:
   - [v0.0.1 AppImage](https://gitlab.com/parkerhdavis/Seria/-/packages/generic/Seria/0.0.1/Seria_0.0.1_amd64.AppImage)
   - Or browse all releases: [GitLab Releases](https://gitlab.com/parkerhdavis/Seria/-/releases/0.0.1)
2. Make it executable:
   ```bash
   chmod +x Seria_0.0.1_amd64.AppImage
   ```
3. Run it:
   ```bash
   ./Seria_0.0.1_amd64.AppImage
   ```

**Optional: Install to system**
```bash
# Move to /opt (or any location you prefer)
sudo mkdir -p /opt/seria
sudo mv Seria-*.AppImage /opt/seria/seria

# Create a symlink for easy command-line access
sudo ln -s /opt/seria/seria /usr/local/bin/seria
```

**Desktop Integration:**
See `resources/README.md` for instructions on:
- Adding Seria to your application menu
- Setting it as the default app for CSV files
- Installing a custom icon

#### Debian/Ubuntu (.deb package)

For Debian-based distributions (Ubuntu, Linux Mint, Pop!_OS, etc.):

1. Download the .deb package:
   - [v0.0.1 .deb](https://gitlab.com/parkerhdavis/Seria/-/packages/generic/Seria/0.0.1/Seria_0.0.1_amd64.deb)
   - Or browse all releases: [GitLab Releases](https://gitlab.com/parkerhdavis/Seria/-/releases/0.0.1)

2. Install:
   ```bash
   sudo dpkg -i Seria_0.0.1_amd64.deb

   # Install dependencies if needed
   sudo apt-get install -f

   # Launch
   seria
   ```

#### Fedora/RHEL/openSUSE (.rpm package)

For RPM-based distributions:

1. Download the .rpm package:
   - [v0.0.1 .rpm](https://gitlab.com/parkerhdavis/Seria/-/packages/generic/Seria/0.0.1/Seria-0.0.1-1.x86_64.rpm)
   - Or browse all releases: [GitLab Releases](https://gitlab.com/parkerhdavis/Seria/-/releases/0.0.1)

2. Install:
   ```bash
   # Fedora/RHEL
   sudo dnf install ./Seria-0.0.1-1.x86_64.rpm

   # OR openSUSE
   sudo zypper install ./Seria-0.0.1-1.x86_64.rpm

   # Launch
   seria
   ```

### Windows Installation

Seria is available as a portable executable for Windows.

1. Download the Windows executable:
   - [v0.0.1 seria.exe](https://gitlab.com/parkerhdavis/Seria/-/packages/generic/Seria/0.0.1/seria.exe)
   - Or browse all releases: [GitLab Releases](https://gitlab.com/parkerhdavis/Seria/-/releases/0.0.1)

2. Run Seria:
   - Double-click `seria.exe` to launch
   - No installation required - it's a portable executable
   - You can move it anywhere you like (Desktop, Program Files, etc.)

**Note:** Windows may show a SmartScreen warning for unsigned applications. Click "More info" → "Run anyway" to proceed.

### macOS Installation

**Note:** macOS builds are not currently available. macOS support is planned for a future release. Currently supported platforms are Linux and Windows.

## System Requirements

### Minimum Requirements

**All Platforms:**
- 2 GB RAM
- 100 MB free disk space
- 1280x720 screen resolution

**Linux:**
- WebKitGTK 4.1 or later
- GTK 3 or later
- Modern Linux distribution (Ubuntu 20.04+, Fedora 35+, etc.)

**Windows:**
- Windows 10 version 1809 or later
- WebView2 (installed automatically)

### Recommended Requirements

- 4 GB RAM (for large CSV files with 10,000+ rows)
- 1920x1080 or higher screen resolution

## First Launch

When you first launch Seria, you'll see:

- **Clean interface** - No file loaded yet
- **Toolbar** - Open, Save, and other file operations
- **Empty grid** - Ready to open your first CSV
- **Print preview panel** - Hidden by default (toggle with toolbar button)

## Quick Tour

### Main Interface

**Header (Top):**
- **Open** - Open a CSV file
- **Save** - Save changes to the current file
- **Save As** - Save to a new location
- **File Info** - Current file name and status
- **Theme Toggle** - Switch between light and dark mode
- **Settings** - Application preferences

**Editor (Center):**
- **CSV Grid** - Spreadsheet-like editing area
- **Column Headers** - Click to sort, filter icon to filter
- **Row Numbers** - Click and drag to reorder rows
- **Summary Row** - Column statistics at bottom

**Sidebars (Optional):**
- **Left Sidebar** - File tree (toggle with `Ctrl+.`)
- **Right/Bottom Panel** - Print preview (toggle with toolbar button)

### Essential Operations

**Opening a file:**
- Click **Open** button
- Or press `Ctrl+O`
- Or drag and drop a CSV file onto the window
- Or use the file tree sidebar

**Editing a cell:**
- Double-click the cell
- Or click once to select, then press `F2` or `Enter`
- Type your changes
- Press `Enter` to save and move to next row

**Saving:**
- Click **Save** button
- Or press `Ctrl+S`
- File is saved immediately

**Undo/Redo:**
- Undo: `Ctrl+Z`
- Redo: `Ctrl+Shift+Z` or `Ctrl+Y`

## Troubleshooting Installation

### Linux: "Permission denied" error

Make sure the AppImage is executable:
```bash
chmod +x Seria-*.AppImage
```

### Linux: Missing dependencies

If the AppImage won't run, you may need to install FUSE:
```bash
# Ubuntu/Debian
sudo apt install fuse libfuse2

# Fedora
sudo dnf install fuse fuse-libs
```

### Windows: SmartScreen warning

Windows may warn about unrecognized apps. This is normal for unsigned applications. Click "More info" → "Run anyway".
