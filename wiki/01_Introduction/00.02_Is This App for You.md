# Is Seria Right for You?

Seria is built for **game writers, narrative designers, and game designers** who work with structured data in their creative process. If you recognize yourself in any of these scenarios, Seria might be the tool you've been looking for.

---

## You Might Love Seria If...

### You're a Game Writer or Narrative Designer

Spreadsheets feel cold and disconnected from creative work, but traditional writing tools don't integrate with game pipelines. Seria bridges this gap: edit CSV data through writer-friendly Print views (Screenplay, Dialogue, etc.) with bidirectional editing. Your data stays version-control friendly with no export step needed.

### You're a Systems Designer

Excel is overkill for structured data, and Google Sheets requires internet. Seria is a fast, lightweight desktop app optimized for content editing. The primitive data files Seria operates on work everywhere (game engines, Git, pipelines), and the multimodal Print views let you visualize data in ways that match your mental model.

### You Like FOSS and Local-First Apps

Seria is free, open-source, and works entirely offline. CSV/TSV files merge cleanly in Git, and you can extend it with custom Print templates. No, it won't replace LibreOffice Calc, but it'll do far, far more than a text editor.

---

## Common Use Cases

Here are some real-world scenarios where Seria excels:

| Use Case | Why Seria Works |
|----------|-----------------|
| **Writing dialogue for RPGs** | Screenplay or Dialogue Print views let you write naturally while maintaining CSV structure |
| **Quest design** | Track quest data (objectives, rewards, NPCs) in grid form, preview in custom Print layouts |
| **Item databases** | Edit stats and descriptions in CSV, visualize in Record or Corkboard views |
| **Branching narratives** | Manage story nodes, choices, and conditions in structured format |
| **Localization prep** | Organize text keys and content for translation workflows |
| **Game balance** | Track stats, costs, and parameters with filtering and sorting |
