# Seria Documentation

**Seria is a specialized cellular editor for game writers and narrative designers.** It sits on top of primitive data files (**CSV and TSV**, with **JSON coming soon**) and lets you view and edit content in writer-friendly formats.

Think Obsidian, but for game writing.

## The Core Problem Seria Solves

Game writers need primitive data sources (CSV for Git, game engines, pipelines) but spreadsheets kill your flow. Traditional writing tools (Final Draft, Scrivener) are great for writing but require export steps and create multiple sources of truth.

**Seria's solution:** Edit your CSV directly through rich Print views (Screenplay, Dialogue, Corkboard, etc.). No export. No duplication. Just your data in the format that works for what you're doing.
